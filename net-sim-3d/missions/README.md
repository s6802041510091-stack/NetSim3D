# ระบบภารกิจในเกม

แต่ละ `mission_XX/` รวมไฟล์ `scenes/`, `scripts/`, `data/` และคู่มือของด่านนั้นไว้ด้วยกัน ด่าน 01, 02, 03, 05 และ 06 มีระบบเกมอยู่แล้ว ส่วนด่าน 04 มีบทภารกิจแต่ยังไม่มีระบบเกมที่เล่นได้

บทภารกิจฉบับหลักอยู่ที่ `../../ภารกิจ/ด่าน_XX/README.md` โมเดลต้นทางอยู่ที่ `../../3Dmodel/` และฉากทดลองอยู่ที่ `../../Preview/`

## มาตรฐานแท็บติดตามภารกิจ (ทุกด่าน รวมด่าน 4–6 เมื่อสร้าง)

ตกลงกับผู้พัฒนาเมื่อ 12 พ.ย. 2569 — ทุกด่านต้องใช้ `ObjectiveHUD.set_steps()` (ห้ามใช้ `set_objective()` แบบข้อความก้อนเดียวในด่านใหม่)

- แสดง**ขั้นตอนทั้งด่านเรียงเป็นลำดับเลข** ตั้งแต่รับภารกิจจนส่งงาน พร้อมหัวข้อ "ภารกิจที่ N" และชื่อภารกิจ
- ขั้นตอนที่ทำแล้ว: **สีเขียว มี ✓**
- ขั้นตอนที่กำลังทำ: **สีน้ำเงิน ตัวหนา มี ▸** และมีคำอธิบายสั้น ๆ ใต้ขั้นตอนว่าต้องทำอะไร/ไปที่ไหน
- ขั้นตอนที่ยังไม่ถึง: **สีเทาจาง**
- ถ้าภารกิจกำหนดลำดับ (เช่น ด่าน 3 ตรวจเครื่องครู → หน้าห้อง → หลังห้อง) ให้**บังคับลำดับในเกม** ทำข้ามขั้นไม่ได้ และแจ้งว่าต้องทำขั้นไหนก่อน
- ใช้ `ObjectiveHUD.sequence()` เมื่อทำทีละขั้น หรือ `ObjectiveHUD.from_done()` เมื่อบางขั้นทำสลับกันได้
- ถ้ามีแผงด้านขวา (SidePanel) ให้ตั้ง `hud.right_inset` เพื่อไม่ให้แท็บซ้อนใต้แผง
