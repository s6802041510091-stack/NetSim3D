# ด่าน 04 — วิเคราะห์และแก้ปัญหาการ์ดเครือข่าย

บทภารกิจอยู่ที่ `../../../ภารกิจ/ด่าน_04/README.md` (ตกลงรายละเอียดกับผู้พัฒนา 12 พ.ย. 2569)

- `scripts/mission_04_controller.gd` — ลำดับด่าน 11 ขั้น: รับสาย → พบครูสาว → ตรวจอาการ → ตรวจสาย (เลือกเครื่องมือ, LAN Cable Tester) → ทดลองสายกับ STAFF-PC-03 → วิเคราะห์ (5 ตัวเลือกสลับลำดับ) → หยิบ NIC สำรอง → เปลี่ยน NIC → ping + เว็บไซต์ → แจ้งครูสาว → รายงานหัวหน้างาน
- `scripts/mission_04_state.gd` — คะแนน 30/50/20 (ความถูกต้อง: เลือกเปลี่ยน NIC ครั้งแรก 30 / ครั้งที่สอง 15; กระบวนการ 5 จุด × 10)
- `scripts/pc_tower.gd` — เคส PC ของครูสาวใช้โมเดล Blender `assets/models/mission_04/pc_tower_nic.glb` (ต้นฉบับ `3Dmodel/ด่าน_04/`) ผูกฝาข้าง การ์ด NIC ไฟสถานะ และจุดเสียบสายเข้ากับภาพเปลี่ยนการ์ด; เคสที่ STAFF-PC-03 เป็นแบบง่ายที่สร้างในเกม
- `scripts/choice_window.gd` — หน้าต่างเลือกคำตอบ (เลือกผิดแสดงคำใบ้และเลือกใหม่ได้)
- เบราว์เซอร์จำลองอยู่ใน `scripts/computer/desktop_os.gd` (ติดตั้งเฉพาะ STAFF-PC-01 และ STAFF-PC-03 ในด่านนี้)

ทดสอบ: `godot --headless --path net-sim-3d -s res://tools/validate_mission_04.gd` (ตั้งภาษาเป็นไทย) • ภาพ: `tools/capture_mission_04.gd`
