# Background music

Put these two files in this folder (opengameart.org blocks automatic
downloads, so they are downloaded by hand from the pages below — click the
file name under "File(s)"):

| File | Plays | Page |
|---|---|---|
| `LofiLoop.ogg` (1.4 MB) | main menu | https://opengameart.org/content/lofi-hip-hop-loop |
| `calm_track-loop.ogg` (3.4 MB) | in the levels | https://opengameart.org/content/calm-track |

Both are CC0. The game loops them and fades between them; until they are
here the game simply has no music. Volumes: `MUSIC` in `scripts/audio/sound.gd`.
