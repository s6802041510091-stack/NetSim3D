# ตัวละครและ Inventory

- WASD เดิน, Shift วิ่ง, เมาส์มอง
- F เปิดประตู / ใช้คอม / รับสาย / ไปต่อในบทสนทนา (ย้ายจาก E)
- E เปิด–ปิด Inventory, Esc ปิด Inventory; F1 เป็นเมนูพักเดิม
- กระเป๋าเปิดได้ขณะเดินเท่านั้น ไม่แย่งปุ่มพิมพ์ในคอมพิวเตอร์หรือบทสนทนา
  ขณะเปิดจะล็อกเดิน/มอง/โต้ตอบ แต่ไม่ได้หยุดเวลาของโลกทั้งฉาก
- มือขวาและแขนเสื้อแยกจาก `it_support_male_180cm.glb` ตัวเดียวกับตัวละครหลัก
  ใช้รูปทรง/UV/วัสดุผิวและเสื้อเดิม ไม่ใช่มือกล่องสร้างใหม่ เก็บที่ `player_right_arm.glb`
  สร้างซ้ำด้วย `3Dmodel/scripts/extract_player_right_arm.py` พร้อม source SHA256 ใน
  `player_right_arm.source.json`; จัดกระดูกนิ้วเดิมเป็นท่ากำหลวมก่อนส่งออก
  มีท่ามือเปล่ารูปตัว C (`player_right_arm_relaxed.glb`) และท่าจับเฉพาะอุปกรณ์แต่ละชิ้น
  สร้างท่ามือเปล่าด้วยสคริปต์เดิมและอาร์กิวเมนต์ `-- --relaxed`
  (สลับ pose เมื่อถือ/เก็บของ ยังไม่มีการขยับนิ้วต่อเนื่องตามด้ามแต่ละชนิด)
  แสดงผ่าน viewport แยก ไม่ทะลุผนัง
  หรือบังหน้าคอม มีจังหวะแกว่งเดิน/วิ่งและยื่นมือเมื่อโต้ตอบ
- ขาและแขนโมเดลเดิมใช้ procedural bone animation; ไม่แก้ GLB ต้นฉบับ
  ไม่ใช่ชุด motion capture และไม่เปลี่ยน collider หรือกล้องที่ใช้ซูมเข้าคอม
- กระเป๋ามี 24 ช่อง เริ่มว่าง มี API `add_item`, `remove_item`, เลือกช่องดูชื่อ/จำนวน
  ยังไม่เชื่อม pickups/ใช้ไอเท็มในภารกิจ, hotbar, หรือเซฟของข้ามการเข้าเกม
  ไม่แจกอุปกรณ์สมมุติเพื่อทำให้ภารกิจดูเสร็จแล้ว

## มือใกล้กล้องและการถืออุปกรณ์

- มือจากโมเดลเดิมอยู่ใกล้กล้องขึ้นและปรับพื้นที่แสดงตามขนาดหน้าต่าง ไม่ใช้กรอบเล็ก 320px
- ใช้ภาพมือจริงของผู้ใช้เป็นมุมอ้างอิง: แขนเข้าจากขวาล่างเฉียงเข้ากลางจอ
  มองเห็นมือด้านนิ้วโป้ง นิ้วโป้งอยู่ล่างและนิ้วชี้อยู่บน ไม่ใช่หลังมือตั้งตรง
  `HAND_ROTATION` คงที่ (-15, 0, 45 องศา), บิดโมเดลรอบแขน 60 องศา;
  ตอนเดิน/ใช้ของขยับเฉพาะตำแหน่ง ไม่หมุนเปลี่ยนมุมที่กำหนด
- กด E → เลือกช่องที่มีของ → **ถือของที่เลือก**; **เก็บของ / มือเปล่า** เพื่อเอาของลง
- ระหว่างที่ยังไม่เชื่อม pickups ใช้รายการ **ทดลองถือ (ไม่ใช่ของภารกิจ)** ในกระเป๋า
  เพื่อดูคีมย้ำสาย คีมปอกสาย หรือเครื่องทดสอบสาย การทดลองไม่เพิ่มของ ไม่เพิ่มคะแนน
  และไม่ทำขั้นตอนภารกิจแทนผู้เล่น; เลือกรายการแรกเพื่อกลับไปถือของเดิม
- ใช้ GLB จริงจาก `3Dmodel/ด่าน_02/` คัดลอกไว้ที่ `assets/models/tools/`
  จุดจับ/ทิศทางและ `hand_scene` ของแต่ละชิ้นอยู่ใน `scripts/held_item_catalog.gd`
  ท่ามือ `hand_<item_id>.glb` ปรับข้อนิ้วของตัวละครเดิมแยกกัน ไม่ใช้ท่ากำเดียวทุกชิ้น
  ดูวิธีตรวจผิวโมเดลและสร้างซ้ำใน `HAND_GRIPS.md`
- รหัสที่รองรับ: `crimping_tool`, `cable_stripper`, `cable_tester`;
  `equip_item(id)` ต้องมีของในกระเป๋า, `unequip_item()` เก็บของ
  ของที่ยังไม่มีโมเดลจะกดถือไม่ได้; ลบชิ้นสุดท้ายแล้วโมเดลในมือหายด้วย
- ของติดกับจุดจับและแกว่งตามมือ ไม่เปลี่ยนกล้องหลักหรือการชน; ยังไม่มีการเซฟของที่ถือ

ตรวจด้วย `tools/validate_player_presentation.gd` (headless หรือ `-- --capture`
บน renderer จริง): ปุ่ม E/Esc, ล็อกเดิน, ไม่แย่ง input คอม, stack/remove,
กระดูก 6 จุด, walk/idle และ gesture มือ; ทดสอบเดิน/บันไดเดิมแยกต่างหาก
