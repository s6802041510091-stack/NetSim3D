# NetSim3D — หน้าจอและระบบภาษา

สถานะ: ผู้ใช้อนุมัติหน้าแรกและตั้งค่าเดิม และอนุมัติภาพเลือกด่านสองภาษากับการเพิ่มตัวเลือกภาษาแล้ว นำเข้า Godot ตามภาพร่างเรียบร้อย

## งานภาพ

- หน้าแรก: `assets/ui/home_reference_exact.png` (ENG) และ `home_th.png` (ไทย)
- เลือกด่าน: `assets/ui/select_level_th.png` และ `select_level_en.png` เป็นภาพร่างที่อนุมัติโดยตรง การ์ดใช้ชื่อเดียวตามภาษา ไม่มีชื่อรอง
- ตั้งค่า: `assets/ui/settings_th_base.png` และ `settings_en_base.png` รักษาองค์ประกอบของภาพร่าง แต่เว้นส่วนตัวควบคุมเพื่อให้ปุ่มภาษา สไลเดอร์ และตัวเลขเป็นของจริง
- ปุ่มและแถบเสียงวางในพิกัด 1672×943 และปรับสเกลพร้อมภาพ พื้นที่กดตรงกับปุ่มในภาพ รองรับเมาส์และคีย์บอร์ด
- ภาพทั้งหมดสร้าง/แก้ด้วย image_gen ในตัว โดยใช้ภาพร่างที่ผู้ใช้อนุมัติ ไม่ใช้บริการ API แยก
- คำสั่งสำหรับพื้นหลังตั้งค่า: คงฉาก แผงกระจก ข้อความ และตำแหน่งตามภาพร่าง ลบเฉพาะตัวเลือกภาษา รางเสียง มือจับ และตัวเลขเปอร์เซ็นต์ เพื่อวางตัวควบคุม Godot ทับ ภาษาอังกฤษเปลี่ยนเฉพาะข้อความ
- คำสั่งสำหรับหน้าแรกไทย: คงภาพและตำแหน่งทั้งหมด เปลี่ยน PLAY/CONTINUE/SETTINGS/EXIT TO LOBBY เป็น เล่น/เล่นต่อ/ตั้งค่า/กลับล็อบบี้ และแปลบรรทัดคำโปรย
- คำสั่งร่างหน้าเลือกด่านฉบับเต็มเก็บใน `../Preview/UI_เลือกด่าน_สองภาษา/README.md`

## หน้าที่ทำงานจริง

หน้าแรกมี Play, Continue, Settings, Exit to Lobby หน้าเลือกด่านคงกฎปลดล็อกเดิม ด่าน 3–4 ยังไม่เปิดเล่น จึงกดไม่ได้และมีคำอธิบายเมื่อชี้เมาส์ ภาพแสดงไอคอนทั้งหกตามแบบที่อนุมัติ

หน้าโหลดใช้ ResourceLoader เป็นเป้าหมายความคืบหน้า ตัวเลข แถบโหลด และตำแหน่งซองอีเมลใช้ค่าเปอร์เซ็นต์เดียวกัน ซองเคลื่อนจากซ้ายไปขวาตามตัวเลข โดยค่าที่แสดงไม่แซงสถานะโหลดจริง สงวน 100% จนกว่าฉากและระบบภารกิจพร้อม จึงแสดงปุ่มเริ่ม ไม่มีคำแนะนำการควบคุมหรือรายละเอียดเริ่มภารกิจบนหน้าโหลด

หน้าโหลดและปุ่มเริ่มเป็นผู้คุมเมาส์ ทำให้สคริปต์ตัวละครที่จับเมาส์ตอน _ready ไม่ซ่อนเคอร์เซอร์ กดเริ่มด้วยเมาส์แล้วเห็นฉากเกมพร้อมป๊อปอัปวิธีควบคุม (WASD, Mouse, Shift, F, E, F1, Esc) และคำแนะนำเริ่มภารกิจ เกมยังหยุดอยู่จนกด “เข้าใจแล้ว เริ่มเล่น” จากนั้นจึงเริ่มเดินและจับเมาส์ ป๊อปอัปรองรับไทย/ENG เหมือนเมนู

ดอกไม้และใบไม้ยังวนบนเมนูเป็นรอบ 7 วินาที

## ไทย / ENG

ค่าเริ่มต้นเป็นไทย เปลี่ยนภาษาใน Settings ได้ทันทีและบันทึกใน `SavePaths.file("language.cfg")` แยกจากคะแนนและไฟล์ภารกิจ ระดับเสียงเดิมบันทึกใน menu.cfg

`scripts/localization.gd` เป็น autoload L10n และคลาส GameLocale คลังคำแปล `localization/en.json` มี 748 รายการจากข้อความในโปรเจกต์ รวมเมนู HUD บทสนทนา โปรแกรมภารกิจ ปุ่ม เครื่องมือ สรุปคะแนน ป๊อปอัปสอนควบคุม และการค้นหาโปรแกรม

ระบบเก็บต้นฉบับไทยกับข้อความที่แสดงแยกกัน จึงสลับกลับได้ ไม่เปลี่ยนสิ่งที่ผู้เล่นพิมพ์ในช่องกรอก ไม่เปลี่ยน ID/Password ชื่อโฮสต์ คำสั่ง ping หรือข้อมูลบันทึกเกม แปลชื่อเมนูย่อย/รายการเลือกด้วย และรองรับข้อความที่มีตัวเลขหรือรูปแบบ %d/%s

ข้อความที่วาดด้วย draw_string ใช้ GameLocale.text() ก่อนวาด ข้อความภายในรูปภาพ โมเดล หรือไฟล์เสียงไม่ถูกแปลงด้วยคลังคำแปล ภาพหน้าเมนูมีรุ่นไทย/ENG แยกไว้แล้ว

เพิ่มคำแปลโดยอัปเดตคลัง en.json หรือปรับชุดข้อมูลใน tools/locale-en-*.json และ tools/build_locale.cjs แล้วรันตัวสร้าง ห้ามรัน extract_locale.cjs ทับ locale-source.json แล้วนำเลขรายการชุดเดิมมาใช้โดยไม่ตรวจเทียบ เพราะการเพิ่มข้อความอาจทำให้เลขเปลี่ยน

ส่งออกเว็บรวม localization/*.json ไว้โดยชัดเจนแล้ว

## ผลตรวจ

เสียงหน้าแรก: มีไฟล์ LofiLoop.ogg แล้ว เล่นวนผ่าน Music และเล่นต่อระหว่างเลือกด่าน/ตั้งค่า/โหลดจนรอกด Start จากนั้นจึงค่อยลดเสียง เสียง load_complete ผ่าน SoundEffect ดังครั้งเดียวเมื่อครบ 100% แยกจากการซ่อนข้อความโหลด ปรับระดับใน Settings ได้ทั้งคู่ ทดสอบ check_menu_audio.gd จับสัญญาณเสียงจริงได้ (เพลง RMS 0.038, แจ้งเตือน RMS 0.284) และตรวจสลับเมนูเร็วไม่ทำให้เพลงหยุดจาก fade เก่า

Desktop v4 ที่ผู้ใช้อนุมัตินำเข้าแล้ว ใช้วอลเปเปอร์ blue ribbon, ไอคอนภาพ และ Taskbar/Start/Search ที่ใช้งานจริง ปุ่มแอปย่อ–เรียกคืนได้และคงการติดตั้งตามภารกิจ ไม่มี Network Designer รายละเอียดและผลตรวจอยู่ใน ../Preview/UI_Desktop_Windows11/IMPLEMENTATION.md

- ทดสอบปุ่มภาษา การบันทึกภาษา ปุ่มย้อนกลับ สถานะด่าน และคลิกสไลเดอร์ด้วยเมาส์จริง
- ตรวจเปลี่ยนข้อความที่มีตัวเลข บทสนทนา และสลับกลับไทย โดยไม่แก้ข้อความที่ผู้เล่นกรอก
- ตรวจ 179 จุดใน NetPlan EDU, Windows Security, TeamViewer และบทสนทนาด่าน 2: ไม่พบข้อความไทยหลงเหลือในจุดที่ตรวจเมื่อเลือก ENG
- โหลดฉากหลักจริงถึง 100% และเริ่มเกมได้
- ตรวจโหลดครั้งแรกและโหลดซ้ำทั้งไทย/ENG: ซองตรงเปอร์เซ็นต์ทุกเฟรม เมาส์มองเห็นที่ 100% คลิก Start จริงแล้วแสดงป๊อปอัปบนฉาก คลิกปิดป๊อปอัปแล้วเกมเดินต่อและจับเมาส์ได้ ภาพผลตรวจอยู่ใน ../Preview/UI_หน้าโหลด/ready-th.png, ready-en.png, controls-popup-th.png และ controls-popup-en.png
- ภาพจริงเก็บที่ `../Preview/UI_เลือกด่าน_สองภาษา/actual/`
- เทียบภาพกับร่างด้วยตัวอย่าง 82,944 พิกเซล: เลือกด่านไทยต่างเฉลี่ย 0.59%, ENG 0.61%, ตั้งค่าไทย 1.65% (รวมกลีบไม้ที่ขยับและตัวควบคุมจริง)
