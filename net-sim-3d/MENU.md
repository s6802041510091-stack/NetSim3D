# เมนูเข้าเกม

- F5 เปิด `scenes/start_menu.tscn`; F6 ที่ `main.tscn` ยังคงใช้ทดสอบฉากเดิมได้
- Play แสดงครบ 6 ด่าน เปิดใช้ 1, 5, 6; ด่าน 2–4 ปิดปุ่มพร้อมระบุว่ากำลังพัฒนา
- แต่ละด่านใช้โรงเรียนเดียวกัน ติดตั้งเฉพาะแอปภารกิจที่เลือก โทรศัพท์เริ่มทำงานเฉพาะด่าน 6
- Play ไม่ลบเซฟเดิม Continue ใช้ด่านล่าสุดที่โหลดสำเร็จและเซฟภารกิจเดิม
  เริ่มจากจุดเกิด ไม่ได้คืนตำแหน่งยืน/หน้าต่างโปรแกรมเดิม และไม่ใช่เซฟข้ามเครื่อง
- เก็บด่านล่าสุดและเสียงใน `user://netsim3d/menu.cfg`; เซฟภารกิจเดิมไม่เปลี่ยน
- F1 พัก/เล่นต่อได้ รวมตอนใช้คอม; Esc ยังเป็นปุ่มของเกมและโปรแกรมเดิม
- Settings ปรับ 0–100 แยก AudioServer buses: `Music`, `SoundEffect`, `Sound`
  ค่า 0 mute จริง บันทึกทันที ตั้ง bus ของ AudioStreamPlayer ที่เพิ่มภายหลังให้ตรงประเภท
  ตอนนี้ยังไม่มีเสียงจริง ไม่ได้สร้างเพลงหรือเสียงประกอบเพิ่ม
- Exit ยืนยันก่อนกลับ Lobby; Web ใช้ `application/web_lobby_url` ค่าเริ่มต้น `../`
  Native Godot กลับเมนูหลักแทน เพราะไม่มีหน้าเว็บ Lobby

## ทดสอบในเครื่อง / เชื่อมเว็บไซต์จริง

1. Export preset Web ไป `tmp/phase5_web_export/index.html` ที่ราก repository
2. รัน `node net-sim-3d/web/serve.cjs` จากราก repository
3. เปิด `http://127.0.0.1:8765/` → เข้าเกม → เมนู Godot → Exit → Lobby
4. เซิร์ฟเวอร์ bind เฉพาะ loopback ไม่มีการเผยแพร่เว็บไซต์

เว็บจริงควรวาง Lobby ที่ `/` และไฟล์ export ที่ `/game/index.html` พร้อมไฟล์ข้างเคียง
หากโครงสร้างต่างออกไป ตั้ง `application/web_lobby_url` เป็น URL ของ Lobby ก่อน export
ไม่ใช้ URL จาก query string เป็นปลายทาง redirect และไม่เปิด export ด้วย `file://`
หน้า `web/index.html` เป็นตัวอย่างสำหรับทดสอบ ไม่แทนที่เว็บไซต์จริงของผู้ใช้

### ขอบเขตเว็บไซต์จริง (ผู้ใช้ยืนยัน 19 ตุลาคม 2026)

เว็บไซต์หลักจะมีระบบสร้างห้องเรียน / เข้าร่วมชั้นเรียน, Login–Logout,
Lobby ผู้เรียน และ Dashboard คะแนน เกม Godot เป็นเพียงฟังก์ชันหนึ่งของเว็บไซต์
Exit ต้องกลับ Lobby ผู้เรียน โดยไม่ Logout หรือล้าง session ของเว็บไซต์
ตอนนี้ยังไม่มี URL Lobby จริง จึงใช้หน้าตัวอย่างและค่าปลายทางที่เปลี่ยนได้
ยังไม่ได้สร้างระบบสมาชิก ห้องเรียน หรือส่งคะแนนขึ้นเซิร์ฟเวอร์
เซฟปัจจุบันอยู่ในเบราว์เซอร์ ไม่ผูกบัญชีผู้เรียน: ก่อนเชื่อมเว็บไซต์จริงต้องออกแบบ
การแยกเซฟตามผู้ใช้/ห้องเรียนและการตรวจคะแนนที่ฝั่งเซิร์ฟเวอร์ ไม่ใช้เซฟนี้แทนฐานข้อมูลคะแนน

## ตรวจสอบ

`tools/validate_game_menu.gd` ตรวจรายการด่าน, mute/gain/บันทึกเสียง,
โหลดโรงเรียนจริงทั้ง 3 ด่าน, แยกแอป, Continue, pause และกลับเมนู
รันด้วย APPDATA แยกเฉพาะทดสอบ เพื่อไม่เปลี่ยนข้อมูลเล่นจริง

ผลทดสอบ 19 ตุลาคม 2026:
- ตัวตรวจจบด้วย `MENU_VALIDATION_FINISHED failures=0` โหลดฉากจริงทั้ง 3 ด่าน
- Web export สำเร็จ; ทดสอบในเบราว์เซอร์ผ่าน Lobby → เมนู → เลือก Level 1
  → หน้าพร้อมเล่น → ฉากโรงเรียน → F1 พัก → Exit → Lobby ตัวอย่าง
- ปรับ Music เป็น 32% แล้วรีโหลด ยังคง 32%; ไม่มีเสียงจริงให้ตรวจคุณภาพเสียง
- ออกไป Lobby แล้วเข้าใหม่ Continue แสดง Level 1 และโหลดกลับถึงหน้าพร้อมเล่นได้
- ไม่ได้ปรับประสิทธิภาพฉาก และไม่ถือเป็นการตรวจครบทุกภารกิจบนเว็บ
