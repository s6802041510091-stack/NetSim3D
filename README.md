# NetSim3D

โครงงานเกมจำลองการปฏิบัติงานด้านเครือข่ายสามมิติ พัฒนาด้วย Godot และ Blender

## เริ่มจาก 4 หมวดหลัก

| หมวด | อยู่ที่ไหน | เก็บอะไร |
|---|---|---|
| เกม | `net-sim-3d/` | โปรเจกต์ Godot และไฟล์ที่เกมใช้งานจริง; ระบบภารกิจอยู่ใน `missions/mission_01` ถึง `mission_06` |
| โมเดล | `3Dmodel/` | ไฟล์ Blender, GLB ต้นทาง, อุปกรณ์ใช้ร่วมกัน และโมเดลเฉพาะด่าน |
| ภารกิจ | `ภารกิจ/` | บทภารกิจและข้อกำหนด แยกเป็น `ด่าน_01` ถึง `ด่าน_06` |
| Preview | `Preview/` | งาน lookdev, ภาพตัวอย่าง และโปรเจกต์ทดลองที่ยังไม่ใช่ฉากเกมหลัก |

เปิดเกมจาก `net-sim-3d/project.godot` ไฟล์ใน `Preview/` ไม่ได้ถูกโหลดเข้าฉากหลักโดยอัตโนมัติ ส่วนโมเดล Blender ต้นทางอยู่ใน `3Dmodel/ใช้ร่วมกัน/blend/` และไฟล์ GLB ที่เกมใช้อยู่จริงอยู่ใน `net-sim-3d/assets/models/` ไม่ใช่ `3Dmodel/ใช้ร่วมกัน/exports/`

`เอกสาร/` และ `หนังสือแหล่งอ้างอิง บทที่8/` เป็นเอกสารส่วนตัว/ภาพแหล่งอ้างอิงที่ยังแยกจากสี่หมวดนี้และไม่ได้ใส่ในรีโปสาธารณะ
