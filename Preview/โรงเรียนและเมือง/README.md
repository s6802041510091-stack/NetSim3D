# Preview โรงเรียนและเมือง

`working/classroom_shell_lookdev.blend` เป็นงานปรับภาพโรงเรียนที่ยังไม่ได้แทนโมเดลในเกมหลัก ส่วน `town/school_with_japanese_town.blend` เป็นฉากโรงเรียนกับเมืองญี่ปุ่นสำหรับดูภาพรวม

`phase0/` ถึง `phase4/` และ `exterior_windows/` เก็บขั้นตอนทดลอง ภาพ และผลตรวจเดิม โดยคงชื่อไฟล์ภายในแต่ละชุดไว้เพื่อให้ย้อนตรวจได้ โปรเจกต์ทดลอง Godot อยู่ในโฟลเดอร์ `godot_preview/` ของแต่ละชุด

ต้นฉบับโมเดลเมืองญี่ปุ่นที่มีใบอนุญาตอยู่ใน `../../3Dmodel/ใช้ร่วมกัน/external/japanese_town/` และข้อมูลเครดิตยังอยู่ใน `town/ATTRIBUTION.md`
