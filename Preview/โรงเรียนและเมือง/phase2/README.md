## งานที่ทำ

ปรับวัสดุของชิ้นส่วนอาคาร 478 วัตถุในแผนที่ทั้งหมด ยึดสีและระดับรายละเอียดของ Phase 1 ที่อนุมัติแล้ว

- ผนังสีขาวอุ่นผิวละเอียด และบัวพื้นสีเทา
- กระเบื้องขนาด 60 × 60 ซม. ในโถง ห้องคอม ห้องเรียน ห้องพักครู และส่วนต่อของสำนักงาน IT
- กระเบื้องกันลื่น 30 × 30 ซม. ในห้องน้ำ
- ผิวคอนกรีตละเอียดสำหรับบันได ชานพัก และห้องเก็บอุปกรณ์
- ฝ้าแผ่น 60 × 60 ซม. พร้อมรอยต่อขนาดเล็ก
- ประตูลายไม้แนวตั้งที่ UV ตามบานประตูเมื่อหมุน
- วงกบ/กรอบหน้าต่างโลหะพ่นสี และราวบันได/กรอบกระจกอะลูมิเนียมขัด
- ยางกันลื่นบริเวณขอบขั้นบันได
- กระจกโปร่งใสสองด้าน และแถบฝ้ากั้นโซน Server
- ผิวแผ่นพื้นยก Server คงช่อง/ลายแผ่นเจาะรูจากโมเดลเดิม
- ขอบรับแสงขนาดเล็ก 448 วัตถุ ใช้ modifier โดยเก็บ geometry ต้นฉบับไว้

ใช้ Texture ใหม่ 5 ชุด รวม 15 ภาพ (Base Color, Roughness, Normal) และใช้วัสดุจาก Phase 1 ร่วมกันสำหรับผนัง กระเบื้อง ไม้ โลหะพ่นสี และยาง วัสดุทั้งหมดฝังภาพไว้ในไฟล์ Blender

Texture เป็นลายพื้นผิวที่สร้างสำหรับโครงการด้วยสูตร ไม่ใช่ภาพถ่ายหรือภาพดาวน์โหลดจากบุคคลที่สาม ไม่อบเงาถาวรลง Base Color

## ผลตรวจ

`verification.json` ตรวจผ่าน: วัตถุเดิมจาก Phase 1 ครบ 10,506 วัตถุ ชื่อ parent ตำแหน่ง geometry พื้นฐาน custom properties และสถานะซ่อนยังเดิม เปลี่ยนเฉพาะวัสดุ/UV/modifier ของชิ้นส่วนตามรายการ `changes.json`

ความกว้างโถงยังเป็น 5.929014 เมตร หน้าจอ 29 จุดคงตำแหน่งและ geometry เดิม ไฟล์ต้นฉบับ 168 ไฟล์ตรงกับ hash ที่บันทึกก่อนเริ่มงาน

Godot 4.7.1 Compatibility นำเข้าแผนที่ทดสอบพร้อมวัสดุได้ ตรวจ Texture ทั้งสามช่องของวัสดุ PBR ใหม่ และตรวจ alpha/การแสดงสองด้านของกระจกผ่าน (`godot_preview/import_validation.json`) ตรวจภาพมองจากโถงเข้าห้องคอมและจากห้องกลับออกโถงแล้ว

กระจกใช้ alpha โปร่งใสที่ส่งผ่าน glTF ได้ Godot นำเข้าเป็น Alpha Depth Pre-pass ไม่พึ่ง screen refraction เพื่อใช้กับ Compatibility ได้

## การอ่านภาพ

ภาพ Blender ก่อน–หลังใช้กล้อง แสง และค่าการเรนเดอร์เดียวกัน แสงเสริมสำหรับตรวจวัสดุรวมถึงบริเวณบันไดอยู่เฉพาะตอนเรนเดอร์ ไม่ได้บันทึกทับชุดไฟในแผนที่

ภาพ Godot ใช้ไฟตัวอย่างเพื่อดูวัสดุและความโปร่งใส ยังไม่มี lightmap/การปรับแสงเกมจริง จึงไม่เท่ากับ Cycles ใน Blender การปรับแสงและตรวจความเร็วเว็บทั้งแผนที่อยู่ใน Phase 5

Phase นี้ไม่ได้ปรับเฟอร์นิเจอร์ทุกชิ้นหรืออุปกรณ์ภารกิจที่เหลือ ซึ่งเป็นงาน Phase 3–4 และยังไม่ได้รวมเข้า main.tscn หรือ GLB ของเกมหลัก การเปิดประตู การกดคอมพิวเตอร์ และ collision ในเกมหลักต้องทดสอบตอนรวมรุ่นแผนที่กับตำแหน่ง/โถงใหม่พร้อมกัน
