# Preview

- `โรงเรียนและเมือง/` — lookdev โรงเรียน หน้าต่าง เมืองญี่ปุ่น ฉากหลัง และผลตรวจแต่ละ Phase

- `ด่าน_01/` ถึง `ด่าน_06/` — จุดเริ่มต้นสำหรับดูตัวอย่างเฉพาะด่าน
