## คีมเข้าหัวสาย (`CrimpingTool`)
ขนาดจริง: ยาว 24 ซม. · หน่วยเมตร · origin อยู่ที่แกนหมุน (น็อตกลางคีม)

```
CrimpingTool
└ CrimpingTool
  ├ Body_Fixed      ปากบน (ช่อง 8P, ใบมีดตัด, ร่องปอก) + ด้ามล่างสีน้ำเงิน
  ├ Jaw_Moving      จุดหมุน → หมุนตอนบีบคีม
  │ └ Jaw_Lower     ปากล่าง (ฟันย้ำ 8 ซี่) + ด้ามบนสีดำ
  ├ Crimp_Slot      ช่องย้ำหัว RJ-45 (8P)
  ├ Cut_Point       ใบมีดตัดสาย
  ├ Strip_Point     ร่องปอกสาย
  └ Hand_Grip       จุดจับด้าม (ใช้ผูกกับมือผู้เล่น)
```
จุด `Crimp_Slot` / `Cut_Point` / `Strip_Point`: แกน **-Z ของ node = ทิศที่สาย/หัว RJ-45 สอดเข้าไป** (เหมือน PlugPoint ของ Cable Tester)

```gdscript
@onready var crimper: CrimpingTool = $CrimpingTool

crimper.set_open(1.0)   # อ้าสุด (ค่าเริ่มต้น)   0.0 = หุบสนิท
crimper.squeeze()       # เล่นท่าบีบ → ปล่อย
crimper.get_point("Crimp_Slot")  # เอาไว้ snap หัว RJ-45 ก่อนบีบ
```
| signal | เกิดเมื่อ |
|---|---|
| `squeezed` | ปากคีมหุบสนิท — จังหวะนี้ให้เกมตัดสินผล (ย้ำหัว / ตัด / ปอก ตามว่ามีอะไรอยู่ที่จุดไหน) |
| `released` | คีมอ้ากลับแล้ว |

ปรับใน Inspector: `open_angle_deg` (มุมอ้า), `squeeze_time`, `release_time`

## ที่ปอกสาย (`CableStripper`)
ขนาด 8.4 × 2.3 × 2.9 ซม. · มีห่วงสวมนิ้ว
- `Cable_Hole` = รูสอดสาย (แกน -Z = ทิศสอดสาย) — ในเกมสอดสายเข้ารูแล้วหมุนที่ปอกรอบสาย 1–2 รอบ
- ตัวเครื่องเป็นชิ้นเดียว ถ้าจะทำท่าหมุน ให้หมุน node `CableStripper` รอบแกนสายจากโค้ดเกม

## ยังต้องทำฝั่งเกม
- เพิ่ม collision/`Area3D` สำหรับหยิบและคลิก
- ตรรกะคิดคะแนน (ปอกยาวพอไหม ตัด Ripcord หรือยัง เรียงสีถูกไหม ย้ำแน่นไหม) อยู่ฝั่งเกม — โมเดลมีจุดอ้างอิงและ signal ให้แล้ว
- **กรรไกรตัด Ripcord** ยังไม่ได้ทำ (ไม่อยู่ในรายการงานรอบนี้)
