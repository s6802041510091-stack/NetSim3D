## ข้อควรระวังด้าน Godot

1. **Blender กับ Godot คนละ revision ของทางเดิน:** Blender กว้าง 5.929 เมตร แต่ GLB/ตำแหน่งใน Godot ยังเป็นก่อนขยาย
2. ห้ามรัน exporter เดิมทับเกมทันที ต้องเตรียม GLB, collision และตำแหน่งประตู/NPC/ไฟฝั่งขวาให้ตรงกันในสำเนาทดลอง
3. `ComputerManager` มองหาหน้าจอที่เป็นลูกโดยตรงของ `MapVisual` และชื่อมี `Monitor_Display_Surface` จึงห้ามรวมหน้าจอกับเคสหรือเพิ่ม parent โดยไม่ทดสอบระบบ
4. ชื่อ `StudentPC_Row...` และ `StaffPC_...` ใช้กำหนดเครื่องและภารกิจ ห้ามเปลี่ยนตามมาตรฐานชื่อใหม่โดยพลการ
5. ระบบประตูอ้าง prefix กับส่วน `Leaf`, `Kick_Plate`, `Handle_Base`, `Lever` และตำแหน่งบานพับใน main.tscn ต้องเก็บชิ้นส่วนแยก
6. `collision="box"` และชื่อพื้น/ผนัง/โต๊ะมีผลกับ exporter ห้ามลบ property หรือ rename ก่อนตรวจ
7. Blender Z-up แปลงเป็น Godot Y-up: `(x,y,z)` → `(x,z,-y)`
8. โทรศัพท์ภารกิจเป็นฉาก Godot แยก ไม่ถือว่าแก้ใน Blender แล้วจะเปลี่ยนตามอัตโนมัติ
9. สคริปต์สร้างห้องรุ่นก่อนขยายโถงมีพิกัดเก่า และบางตัวลบ Collection แล้วสร้างใหม่ ห้ามรันเพื่อแก้วัสดุแบบเหมารวม
