# Phase 1 — มุมโต๊ะผู้เล่น IT Support

สถานะ: ผู้ใช้อนุมัติทิศทางภาพและสั่งเริ่ม Phase 2 แล้ว (16 ตุลาคม 2026) ไฟล์ working รุ่นล่าสุดรวมงาน Phase 2 ส่วนสำเนา `classroom_shell_lookdev_before_phase2.blend` เก็บรุ่น Phase 1 ไว้

## เปิดงาน

- Blender: `../working/classroom_shell_lookdev.blend` — แผนที่สำเนาพร้อมวัสดุฝังในไฟล์
- สำรองก่อนเริ่ม: `../working/classroom_shell_lookdev_before_phase1.blend`
- Godot ตัวอย่างแยก: `godot_preview/project.godot` เปิดแล้วกด F6 ที่ preview.tscn หรือ F5
- ภาพก่อน: `renders/before_hero.png`, `renders/before_detail.png`

## สิ่งที่ปรับ

1. โต๊ะผู้เล่น: ลายไม้ ขอบรับแสง ขาโลหะพ่นสี และส่วนยาง
2. เก้าอี้ผู้เล่น: ผิวผ้าสีน้ำเงินเข้ม ผิวโครงโลหะ และขอบเบาะ/พนักพิง โดยแยกข้อมูลจากเก้าอี้ตัวอื่นก่อนแก้
3. คอมพิวเตอร์ผู้เล่น: ผิวพลาสติก โลหะพ่นสี และยาง ไม่เปลี่ยน Mesh หน้าจอที่เกมใช้โต้ตอบ
4. ชั้นแฟ้มด้านเหนือ: ผิวเคลือบสี ปกแฟ้ม และรหัสฉลากแฟ้ม
5. พื้นห้อง IT ด้านเหนือ: กระเบื้อง 60 ซม. พร้อมร่องยาแนว; ผนังเหนือ: ผิวสีละเอียด

พื้นและผนังเป็น Mesh ต่อเนื่อง จึงเปลี่ยนผิวทั้งชิ้นในห้อง ไม่ได้จำกัดเฉพาะพื้นที่ในภาพ ส่วนต้นไม้ ตู้ข้างห้อง และอุปกรณ์อื่นที่เห็นในฉากยังเป็นโมเดลเดิม อยู่ใน Phase ถัดไป

## วัสดุและสิทธิ์ใช้งาน

Texture สร้างขึ้นสำหรับโครงการด้วยสูตรลายพื้นผิว ไม่ใช่ภาพถ่ายหรือ Texture ดาวน์โหลดจากบุคคลที่สาม มี 9 ชุด ชุดละ Base Color / Roughness / Normal รวม 27 ภาพ ขนาด 512 หรือ 1024 พิกเซล ฝังไว้ในไฟล์ Blender แล้ว ไม่อบเงาหรือแสงลง Base Color

ฉลากเป็น Mesh ขนาดเล็กเพื่อส่งออกได้แน่นอน ต้นแบบนี้ยังไม่ได้รวมฉลากเป็น Texture atlas; ควรทำก่อนกระจายไปทั้งฉากเพื่อลดจำนวนวัตถุและ draw calls

## ผลตรวจ

- ตรวจชื่อ ตำแหน่ง และ parent ของวัตถุเดิมครบ 10,376 ชิ้น
- ตรวจ geometry ของ Mesh นอกขอบเขตที่แก้ 8,500 instances ไม่เปลี่ยน
- หน้าจอเดิม 29 จุดไม่ถูกแก้ geometry/ตำแหน่ง
- ไฟล์ต้นฉบับ 168 ไฟล์ตรงกับ hash ของ Phase 0 รวมแผนที่ Blender และเกมหลัก
- ทดสอบนำเข้าฉากแยกใน Godot 4.7.1 แบบ Compatibility: Texture สี/ความหยาบ/Normal ของวัสดุ PBR มาครบ และตรวจพบหน้าจอผู้เล่น
- รายละเอียดตรวจ: `final_verification.json`, `validation.json`, `godot_preview/import_validation.json`

## ข้อจำกัด

ภาพ Blender ใช้ Cycles และแสงสำหรับตรวจวัสดุ โดยภาพก่อน–หลังใช้กล้องและแสงชุดเดียวกัน ไม่ใช่ภาพกราฟิกสุดท้ายของเกม ส่วน Godot ใช้แสงตัวอย่างสำหรับตรวจการนำเข้า ยังไม่ได้ปรับแสงจริงหรือ lightmap จึงมีความต่างด้านแสงและเงา

ยังไม่ได้ทดสอบการกดใช้งานภารกิจในเกมหลักหรือความเร็วบนเว็บ และยังไม่ส่งออกทับ GLB/main.tscn ของเกมจริง การรักษาชื่อและตำแหน่งหน้าจอไม่ใช่หลักฐานว่าระบบโต้ตอบผ่านการทดสอบแล้ว

ไฟล์นี้เป็นต้นแบบสำหรับพิจารณาทิศทางภาพก่อน Phase 2 ไม่ใช่การยกระดับภาพทั้งแผนที่เสร็จสมบูรณ์
