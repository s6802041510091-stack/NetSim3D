# หน้าต่างรอบอาคาร — งานเพิ่มก่อน Phase 5

ตรวจภาพและส่งมอบ 17 ตุลาคม 2026

## ผลงาน

เพิ่มหน้าต่างภายนอก 31 ช่อง ในไฟล์ `../working/classroom_shell_lookdev.blend` พร้อมเจาะช่องผนังจริง กรอบสีเข้ม เสากลาง และกระจกสองด้าน ใช้วัสดุเดิมจาก Phase 1–2 ไม่ย้ายเฟอร์นิเจอร์หรือจุดใช้งาน

- ห้องเรียนคอมพิวเตอร์: เพิ่ม 4 ช่อง (ด้านข้าง 1 ด้านท้าย 3) และเก็บหน้าต่างภายนอกเดิม 3 ช่องไว้
- ห้องพักครู: 5 ช่องรับแสงสูงเหนือชั้นวางและโต๊ะ
- ห้องวิทยาศาสตร์: 7 ช่อง (ด้านข้าง 4 ด้านท้ายเหนือแนวตู้ 3)
- ห้องเก็บอุปกรณ์: 2 ช่องรับแสงเหนือแนวตู้
- สำนักงาน IT Support: 6 ช่อง รวมด้านข้างและด้านเหนือ
- บันได: 3 ช่อง รวมผนังชั้นบน 2 ช่อง
- ปลายโถงทางเดิน: 4 ช่อง ด้านเหนือและใต้ด้านละ 2

ไม่เพิ่มหน้าต่างในห้อง Server รวมพื้นที่ NOC ภายในขอบเขตห้อง Server และไม่เพิ่มในห้องน้ำชาย/หญิง หน้าต่างภายในที่มีอยู่เดิมไม่เปลี่ยน

## การตรวจ

- เปิดไฟล์ที่บันทึกแล้วตรวจซ้ำผ่าน (`verification.json`)
- ตรวจวัตถุเดิม 10,554 ชิ้น: ชื่อ ตำแหน่ง parent, properties, วัสดุ และสถานะซ่อนคงเดิม
- อนุญาตให้ geometry เปลี่ยนเฉพาะผนัง 9 ชิ้นตามรายการ `modified_walls`
- หน้าต่างใหม่ 31 ชุด รวมกรอบ/กระจก 217 วัตถุ
- ทดสอบช่องเปิดด้วย ray 279 จุด และแนวผนังทึบของสามห้องที่เว้น 285 จุด ผ่านทั้งหมด
- จอเดิมครบ 29 จุด; hash ไฟล์ต้นฉบับ 168 ไฟล์ตรงกับ baseline
- ตรวจภาพ Blender ทั้ง 6 มุมแล้ว: east, west, north, south, staff_inside และ science_inside

## ไฟล์สำรองและส่งต่อ

- สำรองก่อนเพิ่ม: `../working/classroom_shell_lookdev_before_exterior_windows.blend`
- รายการตำแหน่ง/ขนาดทุกช่อง: `changes.json`
- สคริปต์: `../../scripts/exterior_windows.py` โหมด `audit`, `build`, `verify`, `render`
- `build` ปฏิเสธการรันซ้ำเมื่อไฟล์ทำงานต่างจากสำรอง จึงไม่สร้างหน้าต่างซ้อนโดยไม่ตั้งใจ

รอบนี้แก้เฉพาะ Blender Lookdev ยังไม่อัปเดต GLB, main.tscn หรือ collision ของเกมหลัก รวมถึง GLB ทดสอบใน Phase 4 ยังเป็นรุ่นก่อนเพิ่มหน้าต่าง ต้องส่งออกใหม่และปรับ collision ให้ตรงช่องเปิดใน Phase 5

ผลตรวจ Phase 1–4 เป็นหลักฐานของแต่ละรุ่นก่อนหน้า หลังเพิ่มหน้าต่างให้ใช้ verification ของงานนี้เป็นสัญญาสำหรับการเปลี่ยน geometry ผนังเพิ่มเติม ไม่ตีความผลตรวจเก่าว่าครอบคลุม revision นี้
