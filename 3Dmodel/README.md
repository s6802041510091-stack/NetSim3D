# โมเดล

- `ใช้ร่วมกัน/` — ฉากโรงเรียน ตัวละคร อุปกรณ์ทั่วไป ไฟล์ Blender, GLB ต้นทาง และคู่มือ
- `ด่าน_01/` ถึง `ด่าน_06/` — อุปกรณ์เฉพาะภารกิจ; ถ้าด่านหนึ่งใช้ของที่อยู่ใน `ใช้ร่วมกัน/` ให้ลิงก์ไปที่เดิมแทนการคัดลอกซ้ำ
- `scripts/` — สคริปต์สร้าง/ตรวจโมเดล
- `temp/` — งานชั่วคราว ไม่ใช่โมเดลฉบับหลัก

ไฟล์ในหมวดนี้เป็นต้นทางหรือไฟล์รอนำเข้าเกม ไม่ใช่หลักฐานว่าโมเดลนั้นถูกวางในฉากเกมแล้ว ให้ดูไฟล์ที่ใช้งานจริงใน `../net-sim-3d/assets/models/`

บทภารกิจใน `../ภารกิจ/` เป็นข้อกำหนดหลัก หากคู่มือเก่าที่มากับแพ็กอุปกรณ์ระบุด่านหรือขั้นตอนต่างกัน ให้ยึดบทภารกิจปัจจุบัน
