# สาย LAN Cat6 5 เมตร และหัว RJ45 แยก

โมเดลต้นฉบับสำหรับ Network Life สร้างด้วย Blender 5.2 สำหรับใช้ประกอบการเรียนรู้
เป็นสายแพตช์ U/UTP สีฟ้าเข้ม หัวใส 8P8C (ที่เรียกกันทั่วไปว่า RJ45) พร้อมหน้าสัมผัสทอง 8 จุด ตัวล็อก และยางหุ้มท้ายหัว
ไม่อิงยี่ห้อ ไม่ใช่แบบผลิตทางวิศวกรรม และไม่ใช่หลักฐานรับรองสมรรถนะ Cat6 ของสายจริง

## รายละเอียดที่ตั้งใจให้ถูกต้อง

- มีหัวต่อ 2 ด้าน ด้านละ 8 หน้าสัมผัส ไม่ใช่หัวโทรศัพท์ RJ11
- เป็นสายตรง: เรียงสีแบบ T568B ทั้งสองด้าน ขา 1–8 ได้แก่ ขาว/ส้ม, ส้ม, ขาว/เขียว, น้ำเงิน, ขาว/น้ำเงิน, เขียว, ขาว/น้ำตาล, น้ำตาล
- ในโมเดลหัวแยก เมื่อมองลงบนด้านหน้าสัมผัส (+Z) โดยปลายเสียบชี้ขึ้น (+Y) ลำดับขาเพิ่มจากซ้ายไปขวา (+X)
- เห็นเส้นสีเฉพาะช่วงเข้าสู่หัวต่อ ส่วนสายหลักหุ้มฉนวนสีน้ำเงิน ไม่ได้แสดงสายเปลือยตลอดเส้น
- ตัวล็อกอยู่ด้านตรงข้ามหน้าสัมผัส ยางหุ้มท้ายหัวต่อเนื่องกับเปลือกสาย
- เปลือกสายเส้นผ่านศูนย์กลาง 6.2 มม. ตัวหัวกว้างประมาณ 11.6 มม. เป็นขนาดออกแบบโดยประมาณ
- ความยาว 5 เมตรในงานนี้วัดตามแนวกึ่งกลางจากปลายหัวหนึ่งถึงปลายอีกหัวหนึ่ง: ส่วนสาย 4,931 มม. + ระยะในหัว 34.5 มม. × 2
- แนวสายด้านในยกข้ามวงสาย ไม่ใช่ปล่อยให้ท่อสายตัดทะลุกัน ตรวจระยะห่างด้วยการสุ่มจุดตามแนวสายถี่ 1 มม. ในขั้นตรวจ GLB
- พลาสติกใสใช้วัสดุ alpha สำหรับส่งออกได้โดยไม่ต้องพึ่งไฟล์ texture ภายนอก ไม่ใช่การจำลองการหักเหของแสงแบบวัสดุจริง

ข้อมูลสีสายเป็นรายละเอียดของโมเดล ไม่ได้เพิ่มบทเรียนการเข้าหัวสายเข้าไปในขอบเขตเควสโดยอัตโนมัติ

## โครงสร้างสำหรับนำไปใช้ภายหลัง

ไฟล์สายเต็มมี root `Cat6_PatchCable_5m` และส่วนสำคัญ:

- `Cable_Jacket`: ผิวสายที่แปลงเป็น mesh แล้ว
- `Plug_A` / `Plug_B`: หัวด้าน A และ B แยกจากผิวสาย
- ภายในแต่ละหัวมี `Plug_Housing`, `Contacts_8Pin`, `Termination_Conductors`, `Latch_Clip`, `Strain_Relief_Boot`, `Boot_Legend` พร้อม suffix `_A` หรือ `_B`
- `MatingTip_A/B`: จุดอ้างอิงปลายเสียบ
- `CableExit_A/B`: จุดสายออกจากท้ายหัว
- `Pin_01_A` ถึง `Pin_08_B`: จุดอ้างอิงขา พร้อมเลขขาและสีใน glTF extras
- `Cable_Start` / `Cable_End`: จุดต้นและท้ายผิวสาย

หัวแยกมี root `RJ45_Plug_Module` และชื่อส่วนประกอบเหมือนข้างต้น แต่ไม่มี suffix
จุดกำเนิดอยู่ที่หน้าปลายเสียบ แกน Blender +Y ชี้เข้าเต้ารับ ส่วนสายอยู่ทาง -Y
หลังส่งออกเป็น glTF/Godot ปลายเสียบชี้ **-Z** และสายต่อออกทาง **+Z**

หาก Socket ของอุปกรณ์เดิมใช้แกน +Z ชี้ออกจากเต้ารับ ให้เริ่มจากจัดแกน root ของหัวให้ตรงกับ Socket แล้วเลื่อนปลายหัวเข้าไปตาม local -Z ประมาณ 8 มม. **เป็นเพียงจุดเริ่มต้นสำหรับจัดฉาก ต้องตรวจการเสียบจริงกับเต้ารับแต่ละเครื่องอีกครั้ง**
ยังไม่ได้ทดสอบการประกบหัวกับทุกโมเดลใน Godot และไม่รับรองระยะเผื่อเชิงกล

## ข้อจำกัดที่ต้องทราบ

**GLB สายเต็มเป็นโมเดลขดแบบคงรูป ไม่ใช่สายที่ยืดหรือโค้งตามอุปกรณ์โดยอัตโนมัติ**
การย้าย `Plug_A` หรือ `Plug_B` อย่างเดียวจะไม่ทำให้ผิวสายตามไปด้วย
การนำไปเชื่อมคอมพิวเตอร์–Switch–Printer ในมินิเกม ต้องสร้างแนวสายใหม่หรือเพิ่มระบบสร้างท่อ/ดัดสายตามเส้นทางใน Godot ภายหลัง
ไม่มีฟิสิกส์สาย แอนิเมชันเสียบ–ถอด หรือโค้ดตรวจเควสในงานชุดนี้

`Latch_Clip` แยก mesh เพื่อเตรียมใช้ทำปฏิสัมพันธ์ แต่ยังไม่มี rig หรือแอนิเมชันการกดตัวล็อก
วัสดุใสควรตรวจลำดับการแสดงผลใน Godot อีกครั้ง โดยเฉพาะกรณีหัวต่อหลายชั้นทับกัน
ทั้งเส้นมี 13 mesh objects ประมาณ 31,748 triangles; หัวแยกมี 6 mesh objects
หากแสดงสายจำนวนมากในฉาก ควรทำ LOD หรือสร้างผิวสายแบบลดจำนวนจุด ไม่ใช่วางโมเดลรายละเอียดเต็มซ้ำจำนวนมาก

## แก้แนวสายหรือสร้างใหม่

ใน Blender มี collection `SOURCE | editable cable path` ซึ่งซ่อนไว้ และ Curve ชื่อ `Cable_Path_EDIT`
เปิด collection นี้และซ่อน `Cable_Jacket` ก่อนแก้เพื่อไม่ให้เห็นสายซ้อน
**Curve ต้นฉบับไม่ได้เชื่อมการอัปเดตอัตโนมัติไปยัง mesh ที่แปลงแล้ว** หลังแก้ต้องแปลงใหม่/ส่งออกใหม่ หรือตั้งค่าเส้นทางในสคริปต์แล้วสร้างใหม่

รันจากโฟลเดอร์ `assets/3Dmodel`:

```powershell
& '.\scripts\run_build_cat6.ps1'
& '.\scripts\run_build_cat6.ps1' -ValidateOnly
```

คำสั่งแรกสร้างไฟล์ Cat6 ชื่อเดิมใหม่และเรนเดอร์ภาพตรวจงาน คำสั่งที่สองนำ GLB ทั้งสองไฟล์กลับเข้า Blender เพื่อตรวจโครงสร้าง หน่วย ขา สี ระยะห่างของสาย และจุดเชื่อม
ใช้ตัวเรียก PowerShell นี้เพื่อให้ TEMP/cache/config ของกระบวนการ Blender อยู่ใน `temp/cat6` บน D: ไม่เรียกสคริปต์ Python ตรงโดยละการตั้งค่า temp

ชุดทดสอบเป็น **Blender GLB roundtrip ไม่ใช่การทดสอบมินิเกมใน Godot**
ไม่ได้แก้ฉาก Godot หรือโมเดล Switch, Laptop และ Printer เดิม
