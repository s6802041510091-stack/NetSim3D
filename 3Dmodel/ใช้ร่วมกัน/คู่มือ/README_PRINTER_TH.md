# NetCare LP-210N — Network Printer สำหรับ Day 1 Q1

เครื่องพิมพ์เลเซอร์เครือข่ายตั้งโต๊ะ สร้างใหม่ใน Blender ด้วยรูปทรงอุปกรณ์สมมติ ไม่ใช่ CAD ของผู้ผลิต ไม่มีฟังก์ชันสแกนหรือถ่ายเอกสาร โมเดลนี้ยังไม่ถูกนำไปแทนเครื่องพิมพ์เดิมในฉากเกม

## ไฟล์สำหรับเปิดดู

- `blend/office_network_printer.blend` — ต้นฉบับ Blender พร้อม Studio และกระดาษตัวอย่างแยก Collection
- `exports/office_network_printer.glb` — ตัวเครื่องพิมพ์สำหรับ Godot
- `exports/printer_printed_sheet_a4.glb` — กระดาษ A4 แยกชิ้นสำหรับนำไปทำแอนิเมชันหรือแสดงผลการพิมพ์
- `renders/office_network_printer_hero.png` — มุมรวมด้านหน้า
- `renders/office_network_printer_rear.png` — ด้านหลังและช่องไฟ
- `renders/office_network_printer_ports_closeup.png` — ช่อง LAN และ USB-B ระยะใกล้
- `renders/office_network_printer_paper_preview.png` — ตัวอย่างกระดาษที่ออกมาวางบนถาดรับ
- `exports/office_network_printer.validation.json` — ผลตรวจโครงสร้าง GLB
- `exports/office_network_printer.roundtrip.json` — ผลทดสอบนำ GLB กลับเข้า Blender

## ส่วนที่สร้างไว้

- ตัวถังพลาสติกสีขาวนวลและเทา ทรงเรียบ ขนาดประมาณ 360 × 352 × 253 มม.
- ถาดป้อนกระดาษด้านหน้าพร้อมมือจับ ตัวเลื่อนกระดาษ และกระดาษในถาด แยกชิ้นสำหรับเลื่อนออก
- ถาดรับกระดาษด้านบนมีช่องเปิดจริง ร่องประคองกระดาษ และลูกกลิ้งบริเวณทางออก
- ช่องระบายอากาศด้านข้าง ยางรองเครื่อง และฝาปิดสำหรับบำรุงรักษา
- พอร์ต LAN แบบ 8P8C/RJ45 พร้อมหน้าสัมผัส 8 จุด และไฟ Link/Activity แยกชิ้น
- ช่อง USB-B แยกจาก LAN ไม่ใช่พอร์ต USB-A หรือ Router WAN
- ช่องไฟ AC แบบ IEC C14 มีขาไฟสามขา ไม่ใช่ช่อง PoE หรือแหล่งจ่ายจากแบตเตอรี่
- จอสถานะ ปุ่ม Power ปุ่ม Go และไฟ Ready แยกชิ้น
- กระดาษ A4 แยกไฟล์ มีข้อความตัวอย่างบนด้านล่าง เพราะแสดงเป็นถาดรับแบบคว่ำหน้าพิมพ์

ในภาพผลิตภัณฑ์ไฟ Ready เปิดและจอแสดง `READY / LAN OFF` โดยไม่ได้แสดงสายไฟ AC ส่วนไฟเครือข่ายปิดเพราะยังไม่ต่อสาย LAN การใช้จริงในเกมต้องผูกสถานะ Ready กับไฟเลี้ยงและสถานะอุปกรณ์ ไม่ได้หมายความว่าเครื่องทำงานได้โดยไม่ใช้ไฟ

ภาพกระดาษเป็นการจัดวางตัวอย่างผลลัพธ์ ไม่ใช่หลักฐานว่าระบบพิมพ์ของเกมทำงานแล้ว

## ชิ้นส่วนสำหรับพัฒนาต่อ

| ชื่อ | หน้าที่ |
|---|---|
| `NetworkPrinter_LP210N` | จุดรวมตัวเครื่อง |
| `Printer_Chassis` | ตัวถังและชิ้นส่วนคงที่ |
| `Input_Cassette_Slide` | จุดเลื่อนถาดป้อนกระดาษ |
| `Input_Paper_Cassette` | ตัวถาด มือจับ ตัวประคอง และกระดาษด้านใน |
| `Output_Tray_And_Rollers` | ถาดรับและลูกกลิ้ง |
| `Paper_Output` | จุดอ้างอิงสำหรับกระดาษที่ออกจากเครื่อง |
| `Port_RJ45_LAN` / `Socket_RJ45_LAN` | ช่อง LAN และจุดวางหัวสาย |
| `LED_LAN_Link` / `LED_LAN_Activity` | ไฟเครือข่ายที่แยกควบคุมได้ |
| `Port_USB_B` / `Socket_USB_B` | ช่อง USB สำหรับเชื่อมต่อโดยตรงกับคอมพิวเตอร์ |
| `Port_AC_C14` / `Socket_AC_Power` | ช่องรับไฟ AC |
| `Status_LCD` / `Status_LCD_Text` | หน้าจอและข้อความตัวอย่างแบบนิ่ง |
| `Button_Power` / `Button_Go` / `LED_Ready` | ส่วนควบคุม |
| `PrintedSheet_A4` | จุดรวมกระดาษในไฟล์แยก |

ใน Blender ด้านหน้าเครื่องคือ −Y ด้านหลัง +Y จุดต่อสายทั้งสามหันออกด้านหลัง หน่วยโมเดลคือเมตร

glTF/Godot ใช้ +Y ขึ้น และด้านหน้าเครื่อง +Z จุด Socket ใช้แกน +Z เฉพาะจุดหันออกจากช่องเสียบ ถาดกระดาษเลื่อนตามแกน +Z ของตัวเครื่องใน Godot

กระดาษอยู่ใน Collection `OPTIONAL | A4 printed sheet` ซึ่งซ่อนไว้ในไฟล์ Blender เริ่มต้น ให้เปิดการมองเห็น Collection นี้เมื่อต้องการตรวจดู ส่วน `.glb` หลักไม่มีแผ่นกระดาษที่กำลังออกมาติดไปด้วย จึงไม่บังถาดหรือแสดงผลพิมพ์ก่อนจบภารกิจ

ไฟล์เหล่านี้เป็นโมเดลเท่านั้น ยังไม่มี Collision, การกด E, การตรวจการเสียบสาย, การพิมพ์ตามคำสั่ง หรือ Animation Clip สำเร็จรูป

## พื้นที่จัดเก็บและสร้างซ้ำ

ทุกไฟล์อยู่ใต้ `D:\Game Network\NetLife3D\assets\3Dmodel` ตัวรันเปลี่ยน Temp/Cache/User Config ของ Blender ให้ไปอยู่ใน `temp/printer` บนไดรฟ D ตัวโปรแกรมใช้ตำแหน่งติดตั้งเดิมบน C โดยไม่สร้างไฟล์งานไว้ที่นั่น

- `scripts/run_build_printer.ps1` — สร้างและเรนเดอร์ใหม่
- `scripts/run_build_printer.ps1 -ValidateOnly` — ตรวจไฟล์ GLB และโครงสร้างชิ้นส่วน

สคริปต์จะเขียนทับเฉพาะไฟล์ผลลัพธ์ของ Printer ตามชื่อที่ระบุ ไม่แก้โมเดล Switch หรือ Laptop หากแก้ `.blend` ด้วยมือให้บันทึกชื่อเวอร์ชันใหม่ก่อนสร้างซ้ำ
