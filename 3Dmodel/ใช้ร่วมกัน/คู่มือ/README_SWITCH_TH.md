# NetCare GS-08 — Switch 8 พอร์ต

โมเดลต้นแบบสำหรับตรวจงาน Day 1 สร้างขึ้นใหม่โดยตรงใน Blender เป็น Switch ตั้งโต๊ะกึ่งสมจริง ใช้โครงสร้างอุปกรณ์เครือข่ายทั่วไปเป็นแนวทาง ไม่ใช่ CAD ที่รับรองขนาดจากผู้ผลิต

## ไฟล์สำหรับเปิดดู

- `blend/office_switch_8port.blend` — ไฟล์ต้นฉบับ Blender พร้อมกล้องและแสงสำหรับตรวจโมเดล
- `exports/office_switch_8port.glb` — โมเดลสำหรับนำเข้า Godot เฉพาะตัวอุปกรณ์ ไม่มีฉากหรือกล้องติดไปด้วย
- `renders/office_switch_8port_hero.png` — ภาพมุมรวม
- `renders/office_switch_8port_front.png` — ภาพด้านหน้าครบ 8 พอร์ต
- `renders/office_switch_8port_ports_closeup.png` — ภาพรายละเอียดช่องเสียบและหน้าสัมผัส
- `renders/office_switch_8port_rear.png` — ภาพด้านหลังและช่องไฟ DC

## รายละเอียด

- ขนาดตัวเครื่องโดยประมาณ 210 × 110 × 32 มม. รวมยางรองสูงประมาณ 36 มม.
- 8 พอร์ต Ethernet แบบ 8P8C (ที่เรียกทั่วไปว่า RJ45) พร้อมหน้าสัมผัส 8 จุดต่อพอร์ต
- เลขพอร์ต 1–8, ตัวถังโลหะ, ช่องระบายอากาศด้านข้าง, ยางรอง และช่องรับไฟ DC ด้านหลัง
- Power LED และ Link/Activity LED แยกวัตถุและวัสดุไว้แล้ว
- ไฟ Power เปิดสำหรับภาพพรีวิว; ไฟ Link ทั้ง 8 พอร์ตปิด เพราะไม่มีสายเครือข่ายเสียบอยู่
- ไม่มีเสาอากาศ, WAN Port หรือส่วนประกอบของ Router ปะปน
- หน่วยไฟล์ส่งออกคือเมตร; glTF ใช้ +Y ขึ้น และด้านหน้าของโมเดลหันไปทาง +Z
- วัสดุ PBR เป็นสีพื้นและคุณสมบัติวัสดุ ไม่ต้องโหลด Texture ภายนอก

## ชื่อชิ้นส่วนสำหรับใช้ภายหลัง

| ชื่อ | หน้าที่ |
|---|---|
| `OfficeSwitch_8Port` | จุดรวมของตัวโมเดล |
| `Chassis` | ตัวถัง ยางรอง ช่องไฟ และชิ้นส่วนคงที่ |
| `Printed_Legends` | ตัวหนังสือและเลขพอร์ต |
| `RJ45_Port_01` ถึง `RJ45_Port_08` | ช่องเสียบพร้อมหน้าสัมผัส |
| `LED_Power` | ไฟ Power |
| `LED_Link_01` ถึง `LED_Link_08` | ไฟ Link/Activity ต่อพอร์ต |
| `Socket_RJ45_01` ถึง `Socket_RJ45_08` | จุดอ้างอิงสำหรับวางปลายสายที่หน้าพอร์ต |
| `Socket_DC` | จุดอ้างอิงช่องไฟด้านหลัง |

จุด Socket เป็น Empty/Node3D สำหรับเตรียมเชื่อมระบบเกม ไม่ได้เป็นระบบตรวจจับการเสียบสายหรือ Collision โดยตัวเอง และโมเดลยังไม่มีตรรกะเปิดไฟตามการเล่น รวมถึงยังไม่ได้แทนที่ Office LAN ใน Day 1 Q1

ใน Blender มี Collection `STUDIO | preview only` สำหรับภาพตัวอย่าง ซ่อน Collection นี้ได้เมื่อต้องการตรวจตัว Switch ล้วน ๆ โดยกล้องและแสงไม่ถูกส่งออกไปใน `.glb`

## พื้นที่จัดเก็บ

ไฟล์งานทั้งหมดอยู่ใต้ `D:\Game Network\NetLife3D\assets\3Dmodel` สคริปต์รันกำหนด Temp, Cache และโฟลเดอร์ผู้ใช้ของ Blender ให้อยู่ใน `temp` บนไดรฟ D โดยตัวโปรแกรม Blender เรียกจากตำแหน่งติดตั้งเดิมบนไดรฟ C

มี `.gdignore` ในโฟลเดอร์ต้นฉบับ ภาพพรีวิว สคริปต์ และไฟล์ชั่วคราว เพื่อให้ Godot ใช้งานไฟล์ใน `exports` โดยไม่พยายามนำเข้าไฟล์งาน Blender ซ้ำอัตโนมัติ

## สร้างซ้ำ

เรียก `scripts/run_build_switch.ps1` เพื่อสร้างโมเดล ส่งออก ตรวจโครงสร้าง และเรนเดอร์ใหม่ สคริปต์จะเขียนทับเฉพาะไฟล์ผลลัพธ์ที่ระบุชื่อไว้ หากแก้โมเดลด้วยมือให้บันทึกเป็นชื่อเวอร์ชันใหม่ก่อนรันซ้ำ
