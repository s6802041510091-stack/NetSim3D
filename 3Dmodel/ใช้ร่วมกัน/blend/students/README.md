# NetSim3D — นักเรียน ม.ปลาย 5 คน

เปิด `students_lineup.blend` เพื่อดูทั้งห้าตัวพร้อมกัน หรือเลือกไฟล์รายตัว:

| ไฟล์ | ทรงผม | ความสูงรวมผมและรองเท้า |
| --- | --- | --- |
| student_male_mullet.blend | ผมสั้นเปิดหน้าผาก (Short crop) | 165 ซม. |
| student_male_two_block.blend | ผมสั้นแสกข้าง (Side part) | 165 ซม. |
| student_female_bob_cut.blend | ผมสั้นซอย (Short pixie) | 160 ซม. |
| student_female_wendy_cut.blend | หางม้า (Ponytail) | 160 ซม. |
| student_female_layer_cut.blend | มวยผม (Tied bun) | 160 ซม. |

คงชื่อไฟล์เดิมไว้เพื่อไม่ให้ลิงก์เดิมเสีย แต่ทรงผมเปลี่ยนเป็นชุดใหม่ตามตารางแล้ว

ชาย: เสื้อเชิ้ตแขนสั้นขาว กางเกงขาสั้นดำ เข็มขัดดำ ถุงเท้าขาว รองเท้าดำ
หญิง: เสื้อเชิ้ตแขนสั้นขาว กระโปรงจีบดำถึงเข่า ถุงเท้าขาว รองเท้าดำ

ใช้โครงร่างจากตัวละครครูเดิม พร้อมโครงกระดูก 163 กระดูกต่อคนและน้ำหนักผิว
ยังไม่มีคลิปแอนิเมชัน ต้องทดสอบการเคลื่อนไหวและปรับ skin weights ก่อนใช้งานจริง
ทรงผมใช้ฐาน MakeHuman CC0 พร้อมภาพพื้นผิวและความโปร่งใส ปรับพอดีกับศีรษะ
มวยผมดัดแปลงจากฐานหางม้า ไม่ใช้ระบบ particle
รูปภาพพื้นผิวบรรจุในไฟล์ Blender แล้ว ไม่ต้องพึ่งพาไฟล์ภาพภายนอก
ไฟล์รายตัววางเท้าที่ Z=0, ด้านหน้าหัน -Y, หน่วยเมตร
ส่งออกเฉพาะคอลเลกชัน STUDENT; ฉาก STUDIO และข้อความในไฟล์รวมใช้ดูตัวอย่างเท่านั้น

สร้างเฉพาะโมเดล ยังไม่ได้เพิ่มตัวละครในแมพหรือโปรเจกต์ Godot

ปรับปรุง 14 ตุลาคม 2026: นักเรียนหญิงทั้งสามตัวลดความกว้างช่วงขาประมาณ 26%
และความหนาประมาณ 20% โดยไล่สัดส่วนกลับสู่ข้อเท้าเดิม พร้อมปรับแนวแขนและช่วงข้อศอก
เก็บสำรองก่อนแก้ไว้ใน `backup_before_limb_refit` และคงความสูง 160 ซม.
ฉบับแก้ทรงผม: ใช้ `rebuild_student_hair_and_arms.py` ต่อจากฉบับลดขา
แล้วรัน `assemble_student_lineup.py` สำหรับไฟล์รวม
