# PC Tower สำหรับด่าน 4

โมเดลสร้างตาม `PC_TOWER_SPEC.md` และ `GPT_TASK_2_SPEC.md` แล้วปรับรายละเอียดสมจริงรอบ 3
ตรวจเทียบกับไฟล์ก่อนปรับรอบ 3 ทั้งใน Blender และ GLB ที่นำเข้ากลับ: ชื่อ parent ตำแหน่ง origin
การหมุน scale และขนาดของทั้ง 14 Object คงเดิม (ค่าคลาดเคลื่อนการคำนวณไม่เกิน 0.002 มม.)
รอบนี้แก้เฉพาะไฟล์ภายใต้ `3Dmodel/ด่าน_04/` ไม่แก้ไฟล์ใน `net-sim-3d/`

- `exports/pc_tower_nic.glb` — โมเดลสำหรับนำเข้า Godot
- `pc_tower_nic.blend` — ต้นฉบับสะอาด ไม่มี Camera/Light และไม่มี Modifier ค้าง
- `previews/pc_tower_closed.png` — ภาพปิดฝา
- `previews/pc_tower_open.png` — ภาพเปิดฝาเห็นภายในและแผงพอร์ตด้านหลัง
- `previews/pc_tower_service_parts.png` — ภาพด้านหลัง เห็นน็อตฝา 2 ตัวและปลั๊กไฟ
- `previews/pc_tower_detail.png` — ภาพใกล้รายละเอียดเมนบอร์ด คาปาซิเตอร์ และฉลาก
- `textures/pc_detail_atlas_1024.png` — atlas ลายวงจรและฉลาก ฝังในทั้ง Blender และ GLB
- `exports/pc_tower_interactions.json` — ชื่อชิ้นส่วน จุดเริ่มต้น แกนถอด และขนาดพื้นที่คลิกที่แนะนำ
- `exports/pc_tower_nic_validation.json` — จำนวนสามเหลี่ยม ขนาด แกน และผลตรวจไฟล์ส่งออก
- `refine_pc_tower.py` / `validate_pc_tower.py` — สคริปต์ปรับรอบล่าสุดและตรวจซ้ำ
- `exports/pc_tower_realism_validation.json` — ผลตรวจรอบ 3 รวมสถานะก่อน/หลังครบ 14 Object
- `revisions/before_realism/` — สำรอง Blender/GLB ก่อนรอบ 3 และข้อมูลขนาด/transform สำหรับตรวจเทียบ

ใช้วัสดุ Principled BSDF และ texture atlas ขนาด 1024 × 1024 เพียงแผ่นเดียว
texture ฝังใน GLB และ pack ใน Blender ไม่ต้องมีไฟล์ภาพภายนอกสำหรับเปิดโมเดล
ตัวเคสรวมฐานยางมีขนาด 0.19 × 0.40 × 0.40 เมตร จุดวาง `PC_Tower` อยู่กึ่งกลางก้นเคส
ไฟล์ส่งออกมี **18,668 สามเหลี่ยม** ขนาดประมาณ **1.23 MB** ใช้วัสดุ PBR 15 แบบ
ขนาดเคสยังเท่าเดิม ขนาดรวมทั้งปลั๊ก/สายใน Blender ประมาณ 0.190 × 0.454 × 0.400 เมตร

## รายละเอียดที่ปรับรอบ 3

- เพิ่มลายวงจร จุดบัดกรี สกรีนตำแหน่งอุปกรณ์ และฉลากบนเมนบอร์ด/PSU/SSD/RAM/NIC
- เพิ่มคาปาซิเตอร์พร้อมฝาโลหะมีรอยบาก ชุดจ่ายไฟ VRM และอุปกรณ์ SMD
- เปลี่ยนใบพัดทั้ง 4 ชุดเป็นทรงโค้งและมีมุมปะทะลม พร้อมแกนกลาง
- เพิ่มขอบโลหะพับและหมุดย้ำด้านในเคส โดยไม่ขยายขนาด `Case_Body`
- ปิดช่องว่างแผงหลังรอบ bracket NIC ด้วยแผ่นโลหะทึบ เหลือช่องพอดี bracket และ RJ45
- จัดสายเป็นห่วงขึ้นด้านหลัง จุดต่ำสุดอยู่เหนือก้นเคส **4 มม.** ไม่ลอดลงใต้โต๊ะ

การจัดสายคงหัวปลั๊ก origin และขนาด XYZ รวมของ `Power_Cable_Plug` เดิมทั้งหมด
ขอบเขต Z ของชิ้นนี้ย้ายจากค่าติดลบมาอยู่ 0.004–0.114314 เมตร ด้วยการเปลี่ยนรูปทรงสาย
จึงยังรักษาขนาดความสูงเดิมประมาณ 0.110314 เมตร โดยไม่เลื่อนหรือย่อ/ขยาย Object
ตำแหน่งหัวปลั๊กและข้อมูลพื้นที่คลิกที่หัวปลั๊กใน `pc_tower_interactions.json` ไม่เปลี่ยน

## โครงสร้าง

```text
PC_Tower
├── Case_Body
├── Side_Cover
├── Interior
├── Power_LED
├── Power_Button
├── Cover_Screw_1
├── Cover_Screw_2
├── NIC_Bracket_Screw
├── Power_Cable_Plug
├── PCIe_Slot_Target
└── NIC_Card
    ├── NIC_Link_LED
    └── NIC_Port_Point
```

`Interior` รวมเมนบอร์ด ช่อง PCIe 4 ช่อง ฮีตซิงก์ CPU พร้อม heatpipe และพัดลม
RAM 2 แถว ชิปเซ็ต M.2 SSD PSU พร้อมฉลากและตะแกรง HDD และ SATA SSD
พัดลมหน้าหลัง แผง USB/จอ/เสียง และสายจัดตามขอบ ไม่มี LAN บนเมนบอร์ด
NIC มี PCB ชิป ขาทอง bracket ช่อง RJ45 แบบมีโพรง และหน้าสัมผัส 8 จุด

## ชิ้นส่วนคลิกรอบ 2

ทั้ง 5 ชิ้นเป็น Mesh แยกและเป็นลูกโดยตรงของ `PC_Tower` พร้อม metadata `interaction_id`
และ `interaction_action` ใน glTF extras ส่วน `PCIe_Slot_Target` เป็น Empty ลูกของ `PC_Tower`

| Object | ตำแหน่งใน Blender (เมตร) | แกนการทำงาน Blender → Godot |
| --- | --- | --- |
| `Cover_Screw_1` | (-0.089, 0.2035, 0.366) | ดึง +Y → -Z; หมุนรอบแกนนี้ |
| `Cover_Screw_2` | (-0.089, 0.2035, 0.040) | ดึง +Y → -Z; หมุนรอบแกนนี้ |
| `NIC_Bracket_Screw` | (0.0733, 0.194, 0.135) | ดึง -X → -X; หมุนรอบแกนนี้ |
| `Power_Button` | (0.058, -0.199, 0.366) | กด +Y → -Z ประมาณ 1 มม. |
| `Power_Cable_Plug` | (0.053, 0.200, 0.048) | ดึง +Y → -Z ประมาณ 45 มม. |
| `PCIe_Slot_Target` | (0.045, 0.145, 0.118) | ใช้ตำแหน่งเท่านั้น ตรง origin ของ NIC |

หัวน็อตฝามีเส้นผ่านศูนย์กลางประมาณ 9 มม. พร้อมลายจับมือหมุน
หัวน็อต NIC มีเส้นผ่านศูนย์กลาง 8.4 มม. น็อตทั้งหมดใช้ origin บนแกนและ apply rotation แล้ว
เกมควรใช้แกนในตาราง ไม่ใช้การหมุนของ Empty เพื่อหาทิศถอด

เพื่อรับคลิก ให้เพิ่ม Area3D/CollisionShape3D หรือระบบ ray picking ของเกมที่ชิ้นเหล่านี้
ไฟล์ interactions ระบุ BoxShape3D ที่แนะนำในพิกัด Godot และตำแหน่งพักของแต่ละชิ้น
GLB มีโมเดลกับ metadata; ยังไม่ได้เพิ่ม logic รับคลิกหรือ collision ของเกม
น็อตฝาเป็นลูกของเคสตามสเปก จึงต้องซ่อน/ถอดน็อตก่อนเลื่อนฝา ส่วนไฟ Power ยังคง parent เดิม

## จุดอ้างอิงสำหรับผูกเข้ากับเกม

| รายการ | Blender (X,Y,Z) เมตร | Godot (X,Y,Z) เมตร |
| --- | --- | --- |
| จุดวางรวม | (0,0,0) | (0,0,0) |
| Origin ฝาข้าง | (-0.0935,0,0.203) | (-0.0935,0.203,0) |
| Origin NIC | (0.045,0.145,0.118) | (0.045,0.118,-0.145) |
| ปาก RJ45 ในพิกัดเคส | (0.036,0.200,0.126) | (0.036,0.126,-0.200) |
| ทิศหน้าเคส | -Y | +Z |
| ทิศถอดฝาและ NIC | -X | -X |
| ทิศเสียบสาย (-Z ของ marker) | -Y | +Z |

เมื่อผูกแอนิเมชัน ให้บันทึกตำแหน่งเริ่มต้นของ `Side_Cover` แล้วเลื่อนแบบสัมพัทธ์
และคืนกลับตำแหน่งเริ่มต้นนั้น เนื่องจาก origin อยู่กึ่งกลางฝาตามสเปก
โค้ดเคสเดิมใช้ Node3D ฝาที่ตำแหน่งศูนย์ จึงไม่ควรนำค่าศูนย์มาเขียนทับฝาของโมเดลโดยตรง

`NIC_Port_Point` เป็น marker เท่านั้น ต้องผูก NetworkPort ของเกมเข้าที่ marker นี้
ไฟสองดวงเป็น mesh แยก เปลี่ยน material override ได้
การ์ดสำรองใช้การ duplicate `NIC_Card` พร้อมลูกทั้งสอง แล้วผูก NetworkPort ใหม่
ตัวโมเดลไม่มีแอนิเมชัน สคริปต์ Godot หรือ collision ของเกมรวมอยู่ในไฟล์
รอบ 3 ไม่แก้ logic เกมและไม่เปลี่ยนจุดที่เกมใช้ผูกชิ้นส่วน

## ไอคอนอุปกรณ์รอบ 2

ไอคอนอยู่ใน `net-sim-3d/assets/ui/mission_04/` เป็น PNG RGBA 512 × 512

ไม่มีโลโก้หรือข้อความชื่ออุปกรณ์ มีเฉพาะเลข 1–8 และ G บนเครื่องทดสอบตามข้อกำหนด
ใช้ชื่อ `tool_*.png` / `part_*.png` ตามสเปก พร้อมสำเนาชื่อสั้นที่โค้ดเกมอ้างอยู่
สคริปต์สร้างซ้ำคือ `render_equipment_icons.py` และผลตรวจอยู่ที่ `exports/equipment_icons_validation.json`

## สร้างและตรวจซ้ำ

รันจากโฟลเดอร์รากของ repository ด้วย PowerShell:

```powershell
& '3Dmodel/ด่าน_04/create_detail_atlas.ps1'
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --python '3Dmodel/ด่าน_04/refine_pc_tower.py'
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --python '3Dmodel/ด่าน_04/validate_pc_tower.py'
```

สคริปต์ปรับรายละเอียดอ่านไฟล์สำรอง `revisions/before_realism/pc_tower_nic.blend` ทุกครั้ง
จึงรันซ้ำได้โดยไม่สะสม geometry ส่วน `build_pc_tower.py` เป็นสคริปต์ของรุ่นก่อนรอบ 3
ไม่ควรใช้แทน `refine_pc_tower.py` เมื่อต้องการไฟล์ฉบับล่าสุด

การตรวจประกอบด้วยโครงสร้าง GLB จริง จำนวนสามเหลี่ยมจาก index buffers ขนาดหลัง import กลับ
ทิศ marker และการตัดกันของผิวสามเหลี่ยมขณะถอด NIC หลังพ้นช่อง PCIe
ตรวจช่วงเลื่อน 10–300 มม. ทุก 5 มม. โดยเอาฝาออกแล้ว การตรวจแบบนี้ไม่แทนการทดสอบแอนิเมชันในเกม
รอบ 3 ตรวจ origin/ขนาด/parent ครบ 14 Object และตรวจแผงหลังด้วย ray 4,714 จุดรอบช่อง bracket
ทุกจุดชนแผ่นโลหะก่อนถึงอุปกรณ์ภายใน ตรวจข้อมูล PNG ที่ฝังใน GLB ยืนยันขนาด 1024 × 1024
และตรวจทุก vertex ของปลั๊ก/สายว่าไม่ต่ำกว่าก้นเคส
