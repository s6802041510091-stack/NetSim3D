## ส่วนที่ 2 — แก้โมเดล `pc_tower_nic.glb` ให้มีชิ้นที่ผู้เล่นคลิกได้

ผู้เล่นจะเปลี่ยน NIC เอง: กด Power ปิด → ถอดสายไฟ → ไขน็อตฝาข้าง 2 ตัว → เลื่อนฝาออก → ไขน็อตยึดการ์ด → ถอดการ์ด → ใส่การ์ดใหม่ → ขันน็อต → ปิดฝา → ขันน็อต → เสียบสายไฟ → กด Power เปิด

เพิ่ม Object แยกชิ้น (เป็นลูกของ `PC_Tower` ไม่ใช่ลูกของชิ้นอื่น ยกเว้นที่ระบุ):

| ชื่อ Object | คืออะไร | หมายเหตุ |
| --- | --- | --- |
| `Cover_Screw_1`, `Cover_Screw_2` | น็อตมือหมุน (thumb screw) ยึดฝาข้างที่ขอบหลังเคส | origin ที่แกนน็อต, แกนน็อตชี้ไปทาง +Y ของ Blender (ออกด้านหลัง), เกมจะหมุนและดึงออกตามแกนนี้ |
| `NIC_Bracket_Screw` | น็อตยึด bracket ของการ์ด NIC กับเคส (ด้านบนของ bracket) | origin ที่แกนน็อต, แกนน็อตชี้ไปทาง -X ของ Blender (ฝั่งเปิดฝา) |
| `Power_Button` | ปุ่ม Power ด้านหน้าเคส แยกจาก `Case_Body` | origin กลางปุ่ม |
| `Power_Cable_Plug` | หัวปลั๊กไฟ IEC เสียบอยู่ที่ PSU ด้านหลัง พร้อมสายสั้นๆ ห้อยลง ~10 ซม. | origin ที่ปากหัวปลั๊ก, เกมจะดึงออกทาง +Y ของ Blender |
| `PCIe_Slot_Target` | Empty ที่จุดกึ่งกลางการ์ดเมื่อเสียบอยู่ในช่อง (ตำแหน่งเดียวกับ origin `NIC_Card` ปัจจุบัน) | ใช้เป็นจุดวางการ์ดใหม่ |

ข้อกำหนด:
- ตำแหน่งชิ้นเดิมทั้งหมดต้องเหมือนเดิม (เกมผูกตำแหน่งไว้แล้ว)
- **ทิศของ Empty**: เกมใช้แค่ตำแหน่งของ Empty ไม่ใช้การหมุน (การ export glTF หมุนแกน Empty) — ไม่ต้องกังวลเรื่องทิศ
- น็อตแต่ละตัวต้องมีหัวน็อตเห็นชัด (เส้นผ่านศูนย์กลางหัว ~8–10 มม.) เพื่อให้คลิกได้
- งบรวมทั้งไฟล์ยัง ≤ 20,000 สามเหลี่ยม
- Export ทับไฟล์เดิม `3Dmodel/ด่าน_04/exports/pc_tower_nic.glb` และอัปเดต `PC_TOWER_DELIVERY.md` + ภาพตัวอย่าง (เห็นน็อตและปลั๊กไฟชัด)
