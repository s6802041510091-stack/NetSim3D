# สเปกโมเดลคอมพิวเตอร์ครูสาว (ด่าน 4) — สำหรับสร้างใน Blender

เป้าหมาย: เคสคอมพิวเตอร์ตั้งโต๊ะแบบ Mid-Tower ที่ **ภายในสมจริง** (ผู้เล่นเปิดฝาข้างแล้วเปลี่ยนการ์ดเครือข่าย NIC) ใช้ในเกม Godot 4 (web export) ด่าน 4 เท่านั้น

## ขนาดและแกน (สำคัญ — เกมวางตำแหน่งตามนี้)

- หน่วยเป็นเมตร, Scale = 1, Apply transforms ก่อน export
- ขนาดภายนอก: กว้าง 0.19 × สูง 0.40 × ลึก 0.40 ม.
- Origin ของทั้งชิ้น: **กึ่งกลางก้นเคส** (วางบนโต๊ะได้พอดี)
- ทิศใน Blender (Z ขึ้น):
  - ด้านหน้าเคส (ปุ่ม Power, ไฟ) หันไปทาง **-Y**
  - ด้านหลังเคส (พอร์ต I/O, ช่องการ์ด) หันไปทาง **+Y**
  - ฝาข้างที่เปิดได้อยู่ด้าน **-X** ; เมนบอร์ดติดผนังด้าน **+X**

## ชิ้นส่วนที่ต้องแยกเป็น Object (ตั้งชื่อตามนี้ทุกตัว)

| ชื่อ Object | คืออะไร | หมายเหตุ |
| --- | --- | --- |
| `Case_Body` | ตัวเคส (ผนังขวา บน ล่าง หน้า หลัง) ด้าน -X เปิดโล่ง | ด้านหน้ามีหน้ากากและปุ่ม Power |
| `Side_Cover` | ฝาข้างด้าน -X | เกมเลื่อนออกเอง, origin กึ่งกลางฝา |
| `Power_LED` | ไฟ Power ด้านหน้า (ชิ้นเล็ก) | เกมเปลี่ยนสีติด/ดับเอง |
| `Interior` | ทุกอย่างภายในที่ไม่ขยับ รวมเป็นชิ้นเดียวได้ | ดูรายการด้านล่าง |
| `NIC_Card` | การ์ดเครือข่าย PCIe ที่ถอดได้ (PCB + ชิป + ขาทอง + แผ่นเหล็ก bracket + ช่อง RJ45) | origin กึ่งกลางการ์ด, วางเสียบอยู่ในช่อง PCIe ล่างสุด |
| `NIC_Link_LED` | ไฟสถานะเล็กๆ ข้างช่อง RJ45 บน bracket (เป็นลูกของ `NIC_Card`) | เกมเปลี่ยนสีเขียว/ดับเอง |
| `NIC_Port_Point` | Empty ที่ปากช่อง RJ45 ของการ์ด | แกน **-Z ของ Empty ชี้เข้าไปในช่อง** (ทิศเสียบสาย), เป็นลูกของ `NIC_Card` |

ตำแหน่ง `NIC_Card` (Blender, เทียบ origin เคส): ประมาณ **X = 0.045, Y = 0.145, Z = 0.118** การ์ดวาง **แนวนอน** (ตั้งฉากกับเมนบอร์ด) ขาทองเสียบในช่อง PCIe บนเมนบอร์ด bracket อยู่ในแผงหลังเคส (+Y) ช่อง RJ45 โผล่ออกหลังเคส ให้ใช้ตำแหน่งใกล้เคียงนี้ได้ ขอแค่การ์ดเลื่อนออกทาง -X ได้โดยไม่ชนชิ้นอื่น

## ภายในเคส (`Interior`) — ต้องดูเหมือนคอมจริง

- เมนบอร์ด ATX (ประมาณ 0.30 × 0.24 ม.) ติดผนัง +X ส่วนบนค่อนไปด้านหลัง มีลายวงจร/ตัวเก็บประจุ/ชิปเล็กๆ
- ซ็อกเก็ต CPU + ฮีตซิงก์ทาวเวอร์ ครีบอะลูมิเนียม + พัดลม
- RAM 2 แถว, ฮีตซิงก์ชิปเซ็ต, M.2 SSD บนบอร์ด
- ช่อง PCIe 3–4 ช่อง (x16 และ x1) และแผ่นปิดช่องด้านหลังเคส
- Power Supply ด้านล่างหลัง (มีฉลาก/ตะแกรงพัดลม)
- ช่องใส่ไดรฟ์ด้านหน้าล่าง: HDD 3.5" และ SSD 2.5"
- พัดลมเคสหน้า (ดูดเข้า) และหลัง (เป่าออก) มีใบพัดจริง
- สาย: 24-pin ATX, 8-pin CPU, SATA data/power, สายหน้าเคส — **จัดสายเรียบร้อยแนบขอบบอร์ด** ไม่พาดกลางเคส
- แผง I/O หลังเคส: USB, จอ (HDMI/VGA), เสียง ฯลฯ ยกเว้นช่อง LAN บนบอร์ด (ให้ใช้ของการ์ด NIC)

## งบประมาณ (เกมเล่นบนเว็บ)

- รวมทั้งไฟล์ ≤ **20,000 สามเหลี่ยม**
- Texture ≤ **1024 px** ต่อแผ่น (รวมเป็น atlas 1–2 แผ่นได้), วัสดุ PBR (Principled BSDF)
- ไม่ใช้ Modifier ที่ยังไม่ Apply, ไม่มีกล้อง/ไฟในไฟล์

## Export

- ไฟล์: `3Dmodel/ด่าน_04/exports/pc_tower_nic.glb` (glTF Binary, +Y Up ตามค่าเริ่มต้น)
- เก็บไฟล์ .blend ต้นฉบับไว้ที่ `3Dmodel/ด่าน_04/` ด้วย
- ส่งภาพตัวอย่าง 2 มุม: ปิดฝา และเปิดฝาเห็นภายใน

## สิ่งที่ Claude จะทำต่อเมื่อได้ไฟล์

นำเข้าแทนเคสที่สร้างด้วยโค้ดเฉพาะคอมของครูสาว, ผูก `Side_Cover`/`NIC_Card`/ไฟสถานะ/จุดเสียบสายเข้ากับภาพเคลื่อนไหวเปลี่ยน NIC เดิม, ตรวจขนาดไฟล์และรันตัวทดสอบด่าน 4
