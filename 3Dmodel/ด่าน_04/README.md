# โมเดลด่าน 04

ใช้ห้องพักครู คอมพิวเตอร์ และ Cable Tester ที่มีอยู่แล้ว บทภารกิจอยู่ที่ `../../ภารกิจ/ด่าน_04/README.md`

โมเดลเคสคอมพิวเตอร์ครูสาวพร้อม NIC ถอดได้อยู่ที่ `exports/pc_tower_nic.glb`
ต้นฉบับอยู่ที่ `pc_tower_nic.blend` และภาพปิดฝา/เปิดฝาอยู่ใน `previews/`
รายละเอียดการส่งมอบและข้อควรใช้เมื่อผูกแอนิเมชันเดิมอยู่ใน [PC_TOWER_DELIVERY.md](PC_TOWER_DELIVERY.md)
รอบ 2 เพิ่มน็อตแยก 3 ตัว ปุ่ม Power ปลั๊กไฟพร้อมสายห้อย และ `PCIe_Slot_Target`
ข้อมูลสำหรับผูกการคลิกอยู่ใน `exports/pc_tower_interactions.json`
ไอคอนอุปกรณ์ 8 ภาพอยู่ใน `../../net-sim-3d/assets/ui/mission_04/`
โมเดลเก็บตำแหน่งชิ้นเดิมไว้ ต้องผูกชิ้นใหม่กับ logic การซ่อมของเกม

รอบ 3 เพิ่มรายละเอียดแผงวงจร ฉลาก ใบพัดและขอบโลหะ ปิดแผงหลังรอบ NIC และจัดสายไฟเหนือโต๊ะ
คง origin และขนาดทั้ง 14 Object ไว้ รวม 18,668 สามเหลี่ยม ใช้ atlas 1024 px หนึ่งแผ่น
สร้างรุ่นล่าสุดด้วย `refine_pc_tower.py` และตรวจด้วย `validate_pc_tower.py`
