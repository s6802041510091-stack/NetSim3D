# ภารกิจที่ 3: ตรวจรับการเชื่อมต่อเครือข่ายห้องคอมพิวเตอร์

## หัวข้อบทเรียน

การตรวจสอบระบบเครือข่าย โดยเน้นการใช้คำสั่งพื้นฐานเพื่อดูข้อมูลเครือข่ายและตรวจสอบการติดต่อกับอุปกรณ์ปลายทาง

## แนวคิดของภารกิจ

หลังจากติดตั้งอุปกรณ์และสาย LAN ในห้องคอมพิวเตอร์เรียบร้อยแล้ว หัวหน้างาน Data Center ต้องการตรวจรับระบบก่อนเปิดใช้งาน จึงมอบหมายให้ผู้เล่นตรวจสอบคอมพิวเตอร์ตัวอย่างภายในห้องจำนวน 3 เครื่อง

ผู้เล่นต้องใช้คำสั่ง `ipconfig` เพื่อดูข้อมูลเครือข่าย และใช้คำสั่ง `ping` เพื่อตรวจสอบว่าเครื่องสามารถติดต่อ Default Gateway ได้หรือไม่ จากนั้นบันทึกผลและนำรายงานกลับไปส่งให้หัวหน้างาน

ภารกิจนี้เป็นเพียงการตรวจสอบและบันทึกอาการ ผู้เล่นยังไม่ต้องวิเคราะห์สาเหตุหรือแก้ไขระบบ การวิเคราะห์และแก้ไขจะดำเนินต่อในภารกิจที่ 4

## สถานที่ดำเนินภารกิจ

1. ห้อง Data Center สำหรับรับภารกิจและส่งรายงาน
2. ห้องคอมพิวเตอร์สำหรับตรวจสอบเครื่องตัวอย่างทั้ง 3 เครื่อง

ห้องพักครู ห้อง Server และห้องวิทยาศาสตร์ไม่ถูกใช้ในภารกิจนี้

## ผู้มอบภารกิจ

หัวหน้างาน Data Center

## เนื้อเรื่อง

หลังการติดตั้งเครือข่ายของห้องคอมพิวเตอร์ใหม่เสร็จสิ้น ฝ่าย IT ต้องตรวจรับการเชื่อมต่อก่อนเปิดห้องให้ครูและนักเรียนใช้งานจริง

เนื่องจากเครื่องนักเรียนทั้งหมดใช้รูปแบบการติดตั้งเดียวกัน หัวหน้างานจึงกำหนดให้สุ่มตรวจเครื่องตัวอย่าง 3 จุด ได้แก่ คอมพิวเตอร์ครู คอมพิวเตอร์นักเรียนด้านหน้าห้อง และคอมพิวเตอร์นักเรียนด้านหลังห้อง

ผู้เล่นมีหน้าที่เรียกใช้คำสั่งตามรายการตรวจ อ่านผลลัพธ์ และบันทึกสถานะตามที่พบ โดยไม่ได้รับอนุญาตให้เปลี่ยนแปลงค่าหรือแก้ไขอุปกรณ์ในขั้นตอนนี้

## บทสนทนาเริ่มภารกิจ

**หัวหน้างาน Data Center:**

> การติดตั้งเครือข่ายในห้องคอมพิวเตอร์เสร็จเรียบร้อยแล้ว ก่อนเปิดใช้งานเราต้องตรวจรับการเชื่อมต่อก่อน

> ให้คุณตรวจคอมพิวเตอร์ตัวอย่าง 3 เครื่องภายในห้อง ได้แก่ เครื่องครู เครื่องนักเรียนด้านหน้า และเครื่องนักเรียนด้านหลัง

> ใช้ ipconfig ดูข้อมูลเครือข่าย แล้วใช้ ping ตรวจสอบการติดต่อกับ Default Gateway จากนั้นบันทึกผลตามที่พบ

> หากพบความผิดปกติ ให้บันทึกไว้ก่อน ห้ามเปลี่ยนค่า ถอดสาย หรือแก้ไขอุปกรณ์ เพราะเราจะนำผลไปวิเคราะห์ในขั้นตอนถัดไป

**ผู้เล่น:**

> รับทราบครับ ผมจะตรวจสอบและบันทึกผลโดยไม่เปลี่ยนแปลงระบบ

หลังจบบทสนทนา ระบบแสดงข้อความ:

> ได้รับภารกิจ: ตรวจรับการเชื่อมต่อเครือข่ายห้องคอมพิวเตอร์

## วัตถุประสงค์ของภารกิจ

ผู้เล่นต้องสามารถ:

1. ใช้คำสั่ง `ipconfig` เพื่อดูข้อมูลเครือข่ายของคอมพิวเตอร์ได้
2. ระบุ IP Address, Subnet Mask และ Default Gateway จากผลคำสั่งได้
3. ใช้คำสั่ง `ping` ตรวจสอบการติดต่อกับ Default Gateway ได้
4. แยกผลการตรวจสอบที่ปกติและผิดปกติได้
5. บันทึกผลการตรวจสอบโดยไม่แก้ไขระบบได้

## คำสั่งที่ใช้

ภารกิจนี้ใช้เพียง 2 คำสั่ง

### ipconfig

ใช้ดูข้อมูลเครือข่ายของคอมพิวเตอร์ เช่น:

- IP Address
- Subnet Mask
- Default Gateway

### ping

ใช้ตรวจสอบว่าคอมพิวเตอร์สามารถติดต่ออุปกรณ์ปลายทางได้หรือไม่ ภารกิจนี้กำหนดให้ตรวจสอบการติดต่อกับ Default Gateway ของแต่ละเครื่อง

ตัวอย่างรูปแบบคำสั่ง:

```text
ping [หมายเลข Default Gateway]
```

ระบบจะเตรียมข้อมูล IP Address และ Default Gateway ไว้ในผลคำสั่ง ผู้เล่นไม่ต้องคำนวณหรือกำหนดหมายเลขเอง

## จุดตรวจสอบ

ผู้เล่นต้องตรวจสอบคอมพิวเตอร์ตัวอย่างภายในห้องจำนวน 3 เครื่อง

| จุด | เครื่องที่ตรวจสอบ | คำสั่งที่ใช้ | ผลที่กำหนด |
| --- | --- | --- | --- |
| 1 | คอมพิวเตอร์ครู | `ipconfig` และ `ping` | ปกติ |
| 2 | คอมพิวเตอร์นักเรียนด้านหน้าห้อง | `ipconfig` และ `ping` | ปกติ |
| 3 | คอมพิวเตอร์นักเรียนด้านหลังห้อง | `ipconfig` และ `ping` | ผิดปกติ |

## ขั้นตอนการเล่น

### ช่วงที่ 1: รับภารกิจ

1. เดินไปหาหัวหน้างาน Data Center
2. กด `E` เพื่อสนทนา
3. อ่านรายละเอียดและรับ Network Inspection Checklist
4. เดินทางไปยังห้องคอมพิวเตอร์

### ช่วงที่ 2: ตรวจสอบคอมพิวเตอร์ครู

1. เดินไปที่คอมพิวเตอร์ครู
2. เมื่ออยู่ในระยะ ระบบแสดงข้อความ `กด E เพื่อตรวจสอบเครือข่าย`
3. กด `E` เพื่อเปิด Command Prompt จำลอง
4. พิมพ์คำสั่ง `ipconfig`
5. อ่านและบันทึก IP Address, Subnet Mask และ Default Gateway
6. พิมพ์ `ping` ตามด้วยหมายเลข Default Gateway ที่แสดง
7. อ่านผลการตอบกลับ
8. เลือกสถานะ `ปกติ`
9. แนบผลคำสั่งลงในรายงาน

ผลที่กำหนด:

- มีข้อมูลเครือข่ายครบถ้วน
- สามารถติดต่อ Default Gateway ได้
- สถานะปกติ

### ช่วงที่ 3: ตรวจสอบคอมพิวเตอร์นักเรียนด้านหน้าห้อง

1. เดินไปที่คอมพิวเตอร์นักเรียนตัวอย่างด้านหน้าห้อง
2. กด `E` เพื่อเปิด Command Prompt จำลอง
3. ใช้คำสั่ง `ipconfig`
4. บันทึกข้อมูลที่แสดง
5. ใช้คำสั่ง `ping` ไปยัง Default Gateway
6. อ่านผลการตอบกลับ
7. เลือกสถานะ `ปกติ`
8. แนบผลคำสั่งลงในรายงาน

ผลที่กำหนด:

- มีข้อมูลเครือข่ายครบถ้วน
- สามารถติดต่อ Default Gateway ได้
- สถานะปกติ

### ช่วงที่ 4: ตรวจสอบคอมพิวเตอร์นักเรียนด้านหลังห้อง

1. เดินไปที่คอมพิวเตอร์นักเรียนตัวอย่างด้านหลังห้อง
2. กด `E` เพื่อเปิด Command Prompt จำลอง
3. ใช้คำสั่ง `ipconfig`
4. บันทึกข้อมูลที่แสดง
5. ใช้คำสั่ง `ping` ไปยัง Default Gateway
6. อ่านผลการตอบกลับ
7. เลือกสถานะ `ผิดปกติ`
8. แนบผลคำสั่งลงในรายงาน

ผลที่กำหนด:

- แสดงข้อมูลเครือข่ายของเครื่อง
- ไม่สามารถติดต่อ Default Gateway ได้
- ผล `ping` แสดงการหมดเวลาหรือไม่ได้รับการตอบกลับ
- สถานะผิดปกติ

ผู้เล่นต้องบันทึกตามผลที่ปรากฏเท่านั้น และยังไม่ต้องระบุสาเหตุของความผิดปกติ

### ช่วงที่ 5: ตรวจสอบรายงาน

เมื่อครบทั้ง 3 เครื่อง ระบบเปิด Network Inspection Report ซึ่งประกอบด้วย:

- ตำแหน่งของเครื่องที่ตรวจ
- IP Address
- Subnet Mask
- Default Gateway
- ผลการใช้คำสั่ง `ping`
- สถานะปกติหรือผิดปกติ
- ผลคำสั่งที่แนบไว้

ผู้เล่นตรวจความครบถ้วนแล้วกด `ยืนยันรายงาน`

### ช่วงที่ 6: ส่งรายงาน

1. ออกจากห้องคอมพิวเตอร์
2. กลับไปยังห้อง Data Center
3. สนทนากับหัวหน้างาน
4. ส่ง Network Inspection Report

## สิ่งที่ห้ามทำในภารกิจนี้

- ห้ามเปลี่ยน IP Address
- ห้ามเปลี่ยน Subnet Mask
- ห้ามเปลี่ยน Default Gateway
- ห้ามถอดหรือเปลี่ยนสาย LAN
- ห้ามรีสตาร์ตคอมพิวเตอร์หรืออุปกรณ์เครือข่าย
- ห้ามเปิดหน้าตั้งค่าเครือข่ายเพื่อแก้ไขค่า
- ห้ามวิเคราะห์สาเหตุของความผิดปกติ
- ห้ามซ่อมหรือเปลี่ยนอุปกรณ์

หากผู้เล่นพยายามใช้เมนูแก้ไข ระบบแสดงข้อความ:

> ภารกิจนี้เป็นขั้นตอนการตรวจสอบ กรุณาบันทึกผลโดยไม่เปลี่ยนแปลงระบบ

## เงื่อนไขผ่านภารกิจ

ผู้เล่นต้องทำครบทุกข้อ:

- ตรวจสอบคอมพิวเตอร์ครบทั้ง 3 เครื่อง
- ใช้ `ipconfig` ครบทั้ง 3 จุด
- บันทึก IP Address, Subnet Mask และ Default Gateway ถูกต้อง
- ใช้ `ping` ครบทั้ง 3 จุด
- เลือกสถานะปกติหรือผิดปกติตรงกับผลคำสั่ง
- แนบผลคำสั่งลงรายงานครบทุกเครื่อง
- ยืนยัน Network Inspection Report
- ส่งรายงานให้หัวหน้างาน Data Center
- ไม่เปลี่ยนแปลงหรือแก้ไขระบบ

## ระบบคะแนนเบื้องต้น

- ตรวจสอบคอมพิวเตอร์ครูถูกต้อง: 25 คะแนน
- ตรวจสอบคอมพิวเตอร์นักเรียนด้านหน้าถูกต้อง: 25 คะแนน
- ตรวจสอบคอมพิวเตอร์นักเรียนด้านหลังถูกต้อง: 25 คะแนน
- บันทึกรายงานครบถ้วน: 15 คะแนน
- ส่งรายงานให้หัวหน้างาน: 10 คะแนน

รวม 100 คะแนน

การใช้คำสั่งผิด บันทึกค่าผิด หรือเลือกสถานะไม่ตรงกับผล ให้หักคะแนนตามจำนวนครั้งที่ผิด โดยคะแนนรวมต้องไม่ต่ำกว่า 0

## บทสนทนาหลังทำภารกิจสำเร็จ

**ผู้เล่น:**

> ผมตรวจสอบเครื่องตัวอย่างครบทั้งสามเครื่องแล้วครับ เครื่องครูและเครื่องนักเรียนด้านหน้าทำงานปกติ แต่เครื่องนักเรียนด้านหลังไม่สามารถติดต่อ Default Gateway ได้ครับ

**หัวหน้างาน Data Center:**

> รับทราบ ตอนนี้เราทราบแล้วว่าเกิดความผิดปกติที่เครื่องใด ขั้นตอนต่อไปต้องวิเคราะห์หาสาเหตุและแก้ไขให้กลับมาใช้งานได้

ระบบแสดงข้อความ:

> ภารกิจที่ 3 เสร็จสิ้น

จากนั้นระบบปลดล็อก:

> ภารกิจที่ 4: การวิเคราะห์และแก้ปัญหาเครือข่าย

## ขอบเขตของภารกิจ

ภารกิจนี้ไม่รวม:

- คำสั่ง `netstat`
- คำสั่ง `tracert`
- คำสั่ง `nslookup`
- การแก้ไขการตั้งค่าเครือข่าย
- การเปลี่ยนสาย LAN
- การซ่อมอุปกรณ์
- การวิเคราะห์ต้นเหตุของความผิดปกติ

## ผลการเรียนรู้ที่คาดหวัง

หลังผ่านภารกิจ ผู้เล่นควรสามารถ:

1. อธิบายได้ว่าคำสั่ง `ipconfig` ใช้ดูข้อมูลใด
2. ระบุ IP Address, Subnet Mask และ Default Gateway จากผลคำสั่งได้
3. อธิบายได้ว่าคำสั่ง `ping` ใช้ตรวจสอบอะไร
4. แยกผล `ping` ที่ติดต่อสำเร็จและไม่สำเร็จได้
5. บันทึกผลการตรวจสอบโดยไม่เปลี่ยนแปลงระบบได้
6. แยกขั้นตอนการตรวจสอบออกจากขั้นตอนการวิเคราะห์และแก้ไขได้
