# ภารกิจที่ 5: ตรวจสอบความปลอดภัยคอมพิวเตอร์ห้องเรียน

## หัวข้อบทเรียน

ซอฟต์แวร์ช่วยงานระบบเครือข่าย โดยเน้นซอฟต์แวร์ดูแลความปลอดภัยเครือข่าย 2 แนวคิด ได้แก่ Firewall และ Anti-Virus

## แนวคิดของภารกิจ

ภารกิจนี้วัดว่าผู้เล่นเข้าใจหน้าที่ของ Firewall และ Anti-Virus หรือไม่ โดยเปลี่ยนเนื้อหาจากคำถามแบบท่องจำให้เป็นการตัดสินใจผ่านโปรแกรม `Windows Security` แบบจำลอง

ผู้เล่นต้องปิดกั้นการเชื่อมต่อที่ไม่ได้รับอนุญาตด้วย Firewall จากนั้นสแกนและกักกันไฟล์ต้องสงสัยด้วย Anti-Virus เมื่อดำเนินการถูกต้อง สถานะของคอมพิวเตอร์จะเปลี่ยนกลับเป็นปลอดภัย

Internet Security ไม่ถูกนำมาเป็นโจทย์แยกในภารกิจนี้ เนื่องจากเป็นชุดซอฟต์แวร์ที่อาจรวมความสามารถของ Firewall และ Anti-Virus ไว้ด้วยกัน ซึ่งอาจทำให้ตัวเลือกและคำตอบทับซ้อนกัน

## ความสอดคล้องกับหนังสือบทที่ 8

หนังสืออธิบายว่าซอฟต์แวร์ดูแลความปลอดภัยเครือข่ายประกอบด้วยโปรแกรมประเภท Firewall, Anti-Virus และ Internet Security รวมทั้งยกตัวอย่างผลิตภัณฑ์ เช่น McAfee, Kaspersky, Norton และ Bitdefender

ชื่อผลิตภัณฑ์เหล่านี้ใช้เป็นตัวอย่างประกอบความรู้ตามหนังสือเท่านั้น ไม่ใช่โปรแกรมที่ผู้เล่นต้องเลือกหรือติดตั้ง เพราะผลิตภัณฑ์หลายรายสามารถให้ความสามารถด้านความปลอดภัยในลักษณะใกล้เคียงกัน ภารกิจจึงใช้ `Windows Security` แบบจำลองเป็นเครื่องมือดำเนินกิจกรรม และวัดความเข้าใจเกี่ยวกับหน้าที่ของ Firewall และ Anti-Virus แทนการจดจำยี่ห้อ

## สถานที่ดำเนินภารกิจ

1. ห้อง Data Center สำหรับรับโทรศัพท์และเริ่มภารกิจ
2. ห้องคอมพิวเตอร์ สำหรับตรวจสอบคอมพิวเตอร์นักเรียนเครื่องเป้าหมาย `PC-R3-L2` (แถวที่ 3 ฝั่งซ้าย เครื่องที่ 2) และแจ้งผลกับครูประจำห้อง

## ตัวละครที่เกี่ยวข้อง

- ผู้เล่น: เจ้าหน้าที่ IT Support
- ครูประจำห้องคอมพิวเตอร์ (ครูผู้ชาย): ผู้โทรแจ้งว่าพบข้อความเตือนบนคอมพิวเตอร์นักเรียน และรับแจ้งผลหลังแก้ไข

## เนื้อเรื่อง

ก่อนเปิดห้องคอมพิวเตอร์ให้นักเรียนใช้งาน ครูประจำห้องพบว่าคอมพิวเตอร์นักเรียนเครื่องหนึ่งแสดงข้อความเตือนด้านความปลอดภัย จึงโทรศัพท์มายังโต๊ะของผู้เล่นในห้อง Data Center โดยตรง

ผู้เล่นต้องไปที่ห้องคอมพิวเตอร์ เปิดโปรแกรม `Windows Security` แบบจำลองบนเครื่องดังกล่าว อ่านข้อความแจ้งเตือน และเลือกวิธีดำเนินการให้เหมาะสมกับปัญหาที่พบ

## บทสนทนาเริ่มภารกิจ

เมื่อโทรศัพท์บนโต๊ะทำงานดังและผู้เล่นกด `E` เพื่อรับสาย:

**ครูประจำห้องคอมพิวเตอร์:**

> สวัสดีครับ ผมครูประจำห้องคอมนะครับ คอมพิวเตอร์นักเรียนเครื่อง PC-R3-L2 ขึ้นข้อความเตือนด้านความปลอดภัย ผมยังไม่กล้าให้นักเรียนใช้ ช่วยมาตรวจสอบให้หน่อยได้ไหมครับ

**ผู้เล่น:**

> ได้ครับ ผมจะไปตรวจสอบให้

หลังจบบทสนทนา ระบบแสดงข้อความ:

> ได้รับภารกิจ: ตรวจสอบความปลอดภัยของคอมพิวเตอร์นักเรียน

## วัตถุประสงค์ของภารกิจ

ผู้เล่นต้องสามารถ:

1. อธิบายได้ว่า Firewall ใช้ควบคุมและปิดกั้นการเชื่อมต่อที่ไม่ได้รับอนุญาต
2. อธิบายได้ว่า Anti-Virus ใช้ตรวจหาและจัดการไฟล์อันตรายในคอมพิวเตอร์
3. เลือกปิดกั้นการเชื่อมต่อจากโปรแกรมที่ไม่รู้จักได้
4. เริ่มการสแกนหาไฟล์ต้องสงสัยได้
5. เลือกกักกันไฟล์ต้องสงสัยแทนการอนุญาตหรือยกเว้นการตรวจสอบได้
6. ตรวจสอบสถานะหลังดำเนินการได้

## รูปแบบโปรแกรมจำลอง

เมื่อผู้เล่นกด `E` ที่คอมพิวเตอร์เป้าหมาย กล้องจะซูมเข้าหาหน้าจอและเปิด Desktop จำลอง ผู้เล่นต้องเปิดโปรแกรม `Windows Security` แบบจำลองจากไอคอนบน Desktop

โปรแกรมจำลองใช้แนวทางหน้าจอของ `Windows Security` และมีสองเมนูหลักที่ใช้ในภารกิจ:

1. `Firewall & Network Protection`
2. `Virus & Threat Protection`

ปรับเมื่อ 13 พ.ย. 2569 (ผู้พัฒนาสั่ง): หน้าตาและการทำงานเหมือน Windows Security ของ Windows 11 และเป็นภาษาอังกฤษล้วน
แถบซ้ายมีครบทุกเมนูแบบของจริง (Home, Virus & threat protection, Account protection, Firewall & network protection, App & browser control, Device security, Device performance & health, Family options, Protection history, Settings) เมนูที่ไม่เกี่ยวกับภารกิจเปิดดูได้และเป็นสีเขียวทั้งหมด ทำหน้าที่เป็นตัวหลอก
คำใบ้ภาษาไทยและปุ่ม `ส่งผลการตรวจสอบ` แสดงเป็นแผงของเกม แยกจากหน้าต่าง Windows ไอคอนทั้งหมดวาดขึ้นเองในเกม ไม่ใช้ภาพของ Microsoft และในโปรแกรมระบุว่า "Simulated for education. Not affiliated with Microsoft."

เนื่องจากเกมมีเป้าหมายเผยแพร่บนเว็บ หน้าจอ `Windows Security` ทั้งหมดเป็นระบบจำลองภายในเกม ไม่มีการเปิดโปรแกรมจริงบนเครื่องของผู้เล่น ไม่มีการสแกนเครือข่ายจริง และไม่มีไฟล์อันตรายจริง

## ขั้นตอนการเล่น

### ช่วงที่ 1: รับภารกิจ

1. โทรศัพท์บนโต๊ะทำงานของผู้เล่นในห้อง Data Center ดังขึ้น
2. ผู้เล่นเดินเข้าใกล้โทรศัพท์และกด `E` เพื่อรับสาย
3. ครูประจำห้องคอมพิวเตอร์แจ้งอาการและหมายเลขเครื่อง `PC-R3-L2`
4. ระบบทำเครื่องหมายตำแหน่งห้องคอมพิวเตอร์เป็นจุดหมาย
5. ผู้เล่นเดินทางไปยังคอมพิวเตอร์นักเรียนเครื่องเป้าหมาย

### ช่วงที่ 2: เปิดโปรแกรม Windows Security แบบจำลอง

1. ผู้เล่นเข้าใกล้คอมพิวเตอร์และกด `E`
2. กล้องซูมเข้าสู่หน้าจอคอมพิวเตอร์
3. Desktop จำลองแสดงไอคอน `Windows Security`
4. ผู้เล่นเปิดโปรแกรม
5. หน้า Home "Security at a glance" แสดงการ์ดทุกส่วน การ์ด `Firewall & network protection` และ `Virus & threat protection` ขึ้นเครื่องหมายเตือนสีเหลือง "Actions recommended" ทั้งคู่
6. ผู้เล่นต้องตัดสินใจเองว่าจะเปิดส่วนใด (จุดตัดสินใจของคะแนนกระบวนการ): ปัญหาแรกคือโปรแกรมที่ไม่รู้จักขอเชื่อมต่อ ต้องเปิด Firewall ก่อน หลังแก้แล้ว ปัญหาไฟล์ต้องสงสัยต้องเปิด Virus & threat protection โดยปุ่ม Quick scan จะกดได้เมื่อตอบหน้าต่างแจ้งเตือนของ Firewall แล้ว

## เกมเพลย์ส่วนที่ 1: Firewall

### เหตุการณ์

เมื่อผู้เล่นเปิดเมนู `Firewall & Network Protection` ระบบแสดงข้อความ:

> โปรแกรมที่ไม่รู้จักกำลังขออนุญาตเชื่อมต่อผ่านเครือข่าย

ข้อมูลประกอบที่แสดง:

```text
Application: Unknown_Update.exe
Publisher: Unknown
Connection: Incoming connection
Status: Waiting for permission
```

ไฟล์และชื่อโปรแกรมข้างต้นเป็นข้อมูลสมมติภายในเกม

### ตัวเลือก

ในเกมแสดงเป็นหน้าต่าง "Windows Security Alert" แบบของจริง (Windows Defender Firewall has blocked some features of this app) พร้อม Name / Publisher / Path

1. `Allow access` — อนุญาตการเชื่อมต่อ
2. `Cancel` — ไม่อนุญาต การเชื่อมต่อจึงยังถูกปิดกั้นไว้
3. ปิด Firewall — กดสวิตช์ `Microsoft Defender Firewall` เป็น Off ในหน้า Domain / Private / Public network (ระบบจะไม่ปิดจริง สวิตช์เด้งกลับเป็น On พร้อมคำใบ้)

### คำตอบที่ถูกต้อง

> `Cancel` (ปิดกั้นการเชื่อมต่อ)

### เหตุผล

โปรแกรมไม่ทราบผู้ผลิตและกำลังขอเชื่อมต่อเข้ามาโดยไม่ได้รับการยืนยัน ผู้เล่นจึงไม่ควรอนุญาตหรือปิดระบบป้องกัน แต่ควรปิดกั้นการเชื่อมต่อไว้ก่อน

### ผลเมื่อเลือกถูก

- ระบบแสดงภาพการเชื่อมต่อถูกปิดกั้น
- สถานะ Firewall เปลี่ยนเป็นสีเขียว
- หน้าจอแสดงข้อความ `Unauthorized connection blocked`

### คำใบ้เมื่อเลือกผิด

หากเลือกอนุญาตการเชื่อมต่อ:

> โปรแกรมนี้ไม่ทราบผู้ผลิตและยังไม่ได้รับการยืนยัน ควรอนุญาตให้เชื่อมต่อหรือไม่

หากเลือกปิด Firewall ชั่วคราว:

> การปิด Firewall จะลดการป้องกันของคอมพิวเตอร์ ลองเลือกวิธีที่ยังคงการป้องกันไว้

ระบบให้ผู้เล่นเลือกใหม่โดยไม่เฉลยคำตอบทันที

## เกมเพลย์ส่วนที่ 2: Anti-Virus

### การเริ่มสแกน

1. ผู้เล่นเปิดเมนู `Virus & Threat Protection`
2. หน้าจอแสดงว่ายังไม่ได้ตรวจสอบเครื่องในวันนี้
3. ผู้เล่นกดปุ่ม `Scan`
4. แถบความคืบหน้าทำงานประมาณ 3–5 วินาที
5. ระบบพบไฟล์ต้องสงสัยจำลองจำนวนหนึ่งไฟล์

ผลการสแกน:

```text
Threats found: 1
File: Student_Game_Crack.exe
Risk level: High
Status: Action required
```

ชื่อไฟล์และภัยคุกคามเป็นข้อมูลสมมติภายในเกม ไม่มีการสร้างหรือใช้งานไฟล์อันตรายจริง

### ตัวเลือก

ในเกมใช้ตัวเลือกแบบของจริง: คลิกรายการภัยคุกคาม `HackTool:Win32/GameCrack.A` (ชื่อสมมติ) เพื่อดูรายละเอียด เลือกการดำเนินการ แล้วกด `Start actions`

1. `Remove` — ลบไฟล์ (ผิด: ยังไม่ได้ยืนยันว่าเป็นไฟล์อันตรายจริง และลบแล้วกู้คืนไม่ได้)
2. `Quarantine` — กักกันไฟล์
3. `Allow on device` — อนุญาตให้ไฟล์ทำงาน

กับดักเพิ่มเติมตามโครงสร้างของโปรแกรมจริง:

- `Add an exclusion` — Virus & threat protection settings → Exclusions → Add an exclusion → File แล้วเลือกไฟล์ใน Downloads
- ปิด `Real-time protection` ในหน้า Virus & threat protection settings

### คำตอบที่ถูกต้อง

> `Quarantine` — กักกันไฟล์

### เหตุผล

เมื่อพบไฟล์ที่มีความเสี่ยงสูงและผู้ใช้ยังไม่ทราบว่าไฟล์ปลอดภัยหรือไม่ การกักกันช่วยป้องกันไม่ให้ไฟล์ทำงานและแยกไฟล์ออกจากพื้นที่ใช้งานปกติ

### ผลเมื่อเลือกถูก

- ไฟล์ถูกย้ายเข้าสู่พื้นที่กักกันจำลอง
- จำนวนภัยคุกคามที่กำลังทำงานเปลี่ยนเป็นศูนย์
- สถานะ Anti-Virus เปลี่ยนเป็นสีเขียว
- หน้าจอแสดงข้อความ `Threat quarantined`

### คำใบ้เมื่อเลือกผิด

หากเลือก `Allow`:

> ไฟล์นี้มีระดับความเสี่ยงสูง การอนุญาตอาจทำให้ไฟล์ทำงานในเครื่องได้

หากเลือก `Add Exclusion`:

> การเพิ่มข้อยกเว้นจะทำให้ Anti-Virus ไม่ตรวจสอบไฟล์นี้อีก ควรใช้กับไฟล์ที่ยืนยันแล้วว่าปลอดภัยเท่านั้น

หากเลือก `Remove`:

> ยังไม่ได้ยืนยันว่าไฟล์นี้เป็นอันตรายจริง ถ้าลบไปแล้วจะกู้คืนไม่ได้ ลองเลือกวิธีที่หยุดไฟล์ไม่ให้ทำงาน แต่ยังเก็บไว้ตรวจสอบได้

หากปิด `Real-time protection`:

> การปิด Real-time protection ทำให้ Anti-Virus ไม่เฝ้าระวังไฟล์ในเครื่อง ลองเลือกวิธีที่ยังคงการป้องกันไว้

ระบบให้ผู้เล่นเลือกใหม่โดยไม่เฉลยคำตอบทันที

## หน้าสรุปผลในโปรแกรม

เมื่อผู้เล่นดำเนินการทั้งสองส่วนถูกต้อง โปรแกรมแสดง:

```text
Security status: Protected

✓ Firewall is active
✓ Unauthorized connection blocked
✓ Virus scan completed
✓ Threat quarantined
```

สีของหน้าจอเปลี่ยนจากสีแดงเป็นสีเขียว

ปุ่ม `ส่งผลการตรวจสอบ` กดได้ตลอด หากกดก่อนที่ทุกส่วนในหน้า Home จะเป็นสีเขียว ระบบจะไม่รับผลและแสดงคำใบ้ให้ตรวจสอบสถานะก่อน (การตรวจสถานะก่อนส่งผลเป็นจุดตัดสินใจหนึ่งของคะแนนกระบวนการ)

## การส่งภารกิจ

1. ผู้เล่นกดปุ่ม `ส่งผลการตรวจสอบ`
2. ออกจากหน้าคอมพิวเตอร์และกลับสู่มุมมองผู้เล่น
3. เดินไปหาครูประจำห้องคอมพิวเตอร์ซึ่งอยู่ในห้องเดียวกัน
4. พูดคุยกับครูเพื่อแจ้งผล

**ผู้เล่น:**

> ตรวจสอบเรียบร้อยแล้วครับ ผมปิดกั้นการเชื่อมต่อจากโปรแกรมที่ไม่รู้จัก และกักกันไฟล์ต้องสงสัยที่ตรวจพบแล้ว เครื่องกลับมาอยู่ในสถานะได้รับการป้องกันแล้วครับ

**ครูประจำห้องคอมพิวเตอร์:**

> ขอบคุณมากครับ แสดงว่า Firewall ช่วยกันการเชื่อมต่อแปลก ๆ ส่วน Anti-Virus ช่วยจัดการไฟล์อันตรายใช่ไหมครับ ตอนนี้ให้นักเรียนใช้เครื่องได้แล้ว

ระบบแสดงข้อความ:

> ภารกิจสำเร็จ: ตรวจสอบความปลอดภัยคอมพิวเตอร์ห้องเรียน

## ระบบคะแนน

ใช้ระบบคะแนนเดียวกับทุกด่าน 100 คะแนน = ความถูกต้อง 30 + กระบวนการ 50 + เวลา 20 (ตกลงกับผู้พัฒนาเมื่อ 13 พ.ย. 2569 แทนแบบเดิมที่เริ่ม 100 แล้วหักครั้งละ 10)

- **ความถูกต้อง 30:** Firewall (ปิดกั้นการเชื่อมต่อ) 15 + Anti-Virus (Quarantine) 15 — เลือกถูกครั้งแรกได้เต็ม ครั้งที่สองได้ 8 หลังจากนั้นได้ 0
- **กระบวนการ 50:** 5 จุดตัดสินใจ จุดละ 10
  1. ส่วนแรกที่เปิดในโปรแกรมคือ Firewall & network protection
  2. ไม่เคยเลือกปิด Firewall
  3. หลังแก้ Firewall แล้ว ส่วนแรกที่เปิดคือ Virus & threat protection
  4. เลือก Quarantine ตั้งแต่ครั้งแรก (ไม่เคย Remove, Allow on device, Add an exclusion หรือปิด Real-time protection)
  5. ทุกส่วนในหน้า Home เป็นสีเขียวตอนกดส่งผลการตรวจสอบครั้งแรก
- **เวลา 20:** ค่าชั่วคราวจนกว่าจะทดลองเล่น — เต็มเมื่อเสร็จภายใน 5 นาที และเป็น 0 ที่ 15 นาที (เริ่มจับเวลาหลังรับสาย)
- การเลือกผิดไม่ทำให้ภารกิจล้มเหลว ผู้เล่นได้รับคำใบ้และเลือกใหม่ได้
- ทุกครั้งที่เริ่มด่านเป็นการเริ่มใหม่ทั้งหมด ไม่เก็บความคืบหน้าจากรอบก่อน

## เงื่อนไขสำเร็จ

ภารกิจสำเร็จเมื่อผู้เล่นทำครบทุกข้อ:

- เปิดโปรแกรม `Windows Security` แบบจำลองบนคอมพิวเตอร์เป้าหมาย
- เลือกปิดกั้นการเชื่อมต่อที่ไม่ได้รับอนุญาต
- เริ่มการสแกนด้วย Anti-Virus
- เลือกกักกันไฟล์ต้องสงสัย
- ตรวจสอบว่าสถานะเปลี่ยนเป็น `Protected`
- ส่งผลการตรวจสอบและแจ้งผลกับครูประจำห้องคอมพิวเตอร์

## ขอบเขตเนื้อหาที่ไม่ใช้ในภารกิจ

- การตั้งค่า Firewall Rule ขั้นสูง
- การกำหนดหมายเลข Port หรือ Protocol
- การติดตั้งซอฟต์แวร์จากผู้ผลิตจริง
- การเปรียบเทียบประสิทธิภาพระหว่าง McAfee, Kaspersky, Norton และ Bitdefender
- การดาวน์โหลดหรือใช้งานไฟล์อันตรายจริง
- การสแกนเครือข่ายหรืออุปกรณ์จริงของผู้เล่น
- การวิเคราะห์ Log ระดับผู้ดูแลระบบ
- การตั้งค่า Internet Security ที่ทับซ้อนกับ Firewall และ Anti-Virus

## สรุปผลการเรียนรู้

ผู้เล่นได้เรียนรู้ผ่านการลงมือทำว่า Firewall ใช้ควบคุมและปิดกั้นการเชื่อมต่อที่ไม่ได้รับอนุญาต ส่วน Anti-Virus ใช้สแกน ตรวจหา และกักกันไฟล์อันตรายในคอมพิวเตอร์ เมื่อเลือกใช้งานเครื่องมือได้ตรงกับปัญหา ระบบจะกลับสู่สถานะปลอดภัย
