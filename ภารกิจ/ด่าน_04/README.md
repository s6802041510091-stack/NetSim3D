# ภารกิจที่ 4: วิเคราะห์และแก้ปัญหาการ์ดเครือข่าย

## หัวข้อบทเรียน

การวิเคราะห์และแก้ปัญหาเครือข่าย โดยฝึกตรวจสอบปัญหาทีละส่วน ตัดสาเหตุที่ไม่เกี่ยวข้อง และเลือกเปลี่ยนอุปกรณ์ที่มีปัญหา

## แนวคิดของภารกิจ

ครูสาวจากห้องพักครูแจ้งว่าคอมพิวเตอร์ไม่สามารถใช้งานอินเทอร์เน็ตได้ ผู้เล่นต้องเดินทางไปตรวจสอบ แยกให้ได้ว่าปัญหาเกิดจากสาย LAN หรือ Network Interface Card (NIC) และเลือกวิธีแก้ไขที่เหมาะสม

ภารกิจออกแบบให้เหมาะกับผู้เรียนระดับ ปวช. ผู้เล่นไม่ต้องถอดน็อต เลือกช่องติดตั้ง ติดตั้ง Driver หรือซ่อมวงจรอิเล็กทรอนิกส์ด้วยตนเอง เกมจะแสดงขั้นตอนเปลี่ยนอุปกรณ์เป็นภาพเคลื่อนไหวอัตโนมัติหลังจากผู้เล่นวิเคราะห์และเลือกคำตอบถูกต้อง

## สถานที่ดำเนินภารกิจ

1. ห้อง Data Center สำหรับรับโทรศัพท์ เริ่มภารกิจ และส่งรายงาน
2. ห้องพักครู สำหรับตรวจสอบและแก้ไขคอมพิวเตอร์ที่มีปัญหา
3. ห้องเก็บอุปกรณ์ข้างห้อง Data Center สำหรับหยิบ NIC สำรอง

## ตัวละครที่เกี่ยวข้อง

- ผู้เล่น: เจ้าหน้าที่ IT Support
- ครูสาว: ผู้แจ้งปัญหา
- หัวหน้างาน Data Center: ผู้รับรายงานหลังจบงาน

## เนื้อเรื่อง

ขณะที่ผู้เล่นอยู่บริเวณโต๊ะทำงานในห้อง Data Center โทรศัพท์มือถือบนโต๊ะดังขึ้น เมื่อผู้เล่นรับสาย ครูสาวจากห้องพักครูแจ้งว่าคอมพิวเตอร์ของเธอไม่สามารถใช้งานอินเทอร์เน็ตได้ และขอให้ผู้เล่นไปช่วยตรวจสอบ

เมื่อไปถึงห้องพักครู ผู้เล่นพบว่าสัญลักษณ์เครือข่ายบนหน้าจอแสดงว่าเครื่องไม่ได้เชื่อมต่อ ผู้เล่นจึงตรวจสอบตั้งแต่ส่วนที่ง่ายและอยู่ใกล้เครื่องที่สุดก่อน ได้แก่ สาย LAN และพอร์ตเครือข่ายของคอมพิวเตอร์

ผลการตรวจแสดงว่าสาย LAN และเส้นทางเครือข่ายใช้งานได้ตามปกติ แต่พอร์ตของ Network Interface Card (NIC) ในเครื่องครูไม่มีไฟสถานะ ผู้เล่นจึงต้องเลือกวิธีดำเนินการจากหลักฐานที่พบ

## บทสนทนาเริ่มภารกิจ

เมื่อผู้เล่นกด `E` ที่โทรศัพท์บนโต๊ะทำงาน:

**ครูสาว:**

> สวัสดีค่ะ คอมพิวเตอร์ที่ห้องพักครูใช้อินเทอร์เน็ตไม่ได้ ช่วยมาตรวจสอบให้หน่อยได้ไหมคะ

**ผู้เล่น:**

> ได้ครับ ผมจะไปตรวจสอบให้

หลังจบบทสนทนา ระบบแสดงข้อความ:

> ได้รับภารกิจ: ตรวจสอบคอมพิวเตอร์ในห้องพักครูที่ไม่สามารถเชื่อมต่อเครือข่ายได้

## วัตถุประสงค์ของภารกิจ

ผู้เล่นต้องสามารถ:

1. ตรวจสอบอาการเบื้องต้นจากสัญลักษณ์เครือข่ายได้
2. ใช้ LAN Cable Tester ตรวจสอบสาย LAN ได้
3. ใช้ผลจากการทดลองสลับอุปกรณ์เพื่อตัดสาเหตุที่ไม่เกี่ยวข้องได้
4. วิเคราะห์ได้ว่าปัญหาเกิดจาก Network Interface Card (NIC)
5. เลือกเปลี่ยน Network Interface Card (NIC) ที่เสียด้วยอุปกรณ์สำรองได้
6. ตรวจสอบผลหลังแก้ไขด้วยคำสั่ง `ping` และการเปิดเว็บไซต์จำลองได้

## ขั้นตอนการเล่น

### ช่วงที่ 1: รับแจ้งปัญหา

1. โทรศัพท์บนโต๊ะทำงานของผู้เล่นในห้อง Data Center ดังขึ้น
2. ผู้เล่นเดินเข้าใกล้โทรศัพท์และกด `E` เพื่อรับสาย
3. ครูสาวแจ้งอาการว่าคอมพิวเตอร์ในห้องพักครูไม่สามารถใช้งานอินเทอร์เน็ตได้
4. ระบบทำเครื่องหมายตำแหน่งห้องพักครูเป็นจุดหมาย

### ช่วงที่ 2: ตรวจสอบอาการเบื้องต้น

1. ผู้เล่นเดินไปยังห้องพักครู
2. พูดคุยกับครูสาวและเข้าใกล้คอมพิวเตอร์ที่มีปัญหา
3. กด `E` เพื่อตรวจสอบคอมพิวเตอร์
4. หน้าจอแสดงสัญลักษณ์ว่าไม่ได้เชื่อมต่อเครือข่าย
5. ผู้เล่นตรวจดูพอร์ตของ Network Interface Card (NIC) และพบว่าไม่มีไฟสถานะ

### ช่วงที่ 3: ตรวจสอบสาย LAN

1. ผู้เล่นเลือก LAN Cable Tester จากรายการอุปกรณ์
2. เกมแสดงภาพการถอดสาย LAN และเชื่อมต่อเข้ากับ LAN Cable Tester
3. ผลการทดสอบแสดงว่าสาย LAN ส่งสัญญาณได้ครบและไม่มีคู่สายขาด
4. ผู้เล่นนำสาย LAN เส้นเดิมของเครื่องที่มีปัญหาไปเชื่อมต่อกับคอมพิวเตอร์อีกเครื่องที่ใช้งานได้ปกติ
5. คอมพิวเตอร์อีกเครื่องสามารถเชื่อมต่อเครือข่ายได้ตามปกติ

ระบบสรุปหลักฐานให้ผู้เล่น:

```text
ผลการตรวจสอบ
✓ สาย LAN ผ่านการตรวจสอบด้วย LAN Cable Tester
✓ เมื่อนำสาย LAN เส้นเดิมไปต่อกับคอมพิวเตอร์อีกเครื่อง เครื่องนั้นใช้งานเครือข่ายได้ตามปกติ
✗ พอร์ตของ Network Interface Card (NIC) ในเครื่องครูไม่มีไฟสถานะ
```

### ช่วงที่ 4: วิเคราะห์และเลือกวิธีแก้ไข

ระบบถามผู้เล่น:

> จากผลการตรวจสอบ ควรดำเนินการอย่างไรต่อไป

ตัวเลือกมี 5 ข้อ ระบบ**สลับลำดับตัวเลือกทุกครั้งที่เล่น** เพื่อไม่ให้ผู้เล่นจำตำแหน่งคำตอบได้ ตัวลวงแต่ละข้อมีหลักฐานจากการตรวจสอบที่หักล้างได้:

| ตัวเลือก | ถูก/ผิด | หลักฐานที่ใช้ตัดสิน |
| --- | --- | --- |
| เปลี่ยนสาย LAN เส้นใหม่ | ผิด | LAN Cable Tester แสดงว่าสายส่งสัญญาณได้ครบ |
| Restart Router และ Switched Hub | ผิด | คอมพิวเตอร์เครื่องอื่นยังใช้งานเครือข่ายได้ตามปกติ |
| ย้ายไปเสียบพอร์ตอื่นบน Switched Hub | ผิด | สายเส้นเดิมและพอร์ตเดิมใช้งานกับคอมพิวเตอร์อีกเครื่องได้ |
| ติดตั้ง Windows ใหม่ | ผิด | เกินความจำเป็น และไม่สอดคล้องกับพอร์ต NIC ที่ไม่มีไฟสถานะ |
| ทดลองเปลี่ยน Network Interface Card (NIC) ด้วยอุปกรณ์สำรอง | **ถูก** | สายและเส้นทางเครือข่ายปกติ แต่พอร์ต NIC ไม่มีไฟสถานะ |

ข้อความแนะนำเมื่อเลือกคำตอบผิด:

- หากเลือกเปลี่ยนสาย LAN:

  > ผลจาก LAN Cable Tester บอกอะไรเกี่ยวกับสายเส้นนี้

- หากเลือก Restart Router และ Switched Hub:

  > ลองพิจารณาว่าคอมพิวเตอร์เครื่องอื่นได้รับผลกระทบด้วยหรือไม่

- หากเลือกย้ายพอร์ตบน Switched Hub:

  > เมื่อนำสายเส้นเดิมไปต่อกับคอมพิวเตอร์อีกเครื่อง ผลเป็นอย่างไร

- หากเลือกติดตั้ง Windows ใหม่:

  > ลองพิจารณาก่อนว่าปัญหาเกิดในระดับซอฟต์แวร์ หรือระดับการเชื่อมต่อทางกายภาพ

ระบบไม่เฉลยคำตอบทันที ผู้เล่นสามารถอ่านหลักฐานและเลือกใหม่ได้ การเลือกผิดหักคะแนนกระบวนการของจุดตัดสินใจนี้

### ช่วงที่ 5: หยิบ NIC สำรองและเปลี่ยนอุปกรณ์

เมื่อผู้เล่นเลือกคำตอบถูกต้อง ระบบแจ้งให้ไปหยิบ Network Interface Card (NIC) สำรอง:

1. ผู้เล่นเดินไปที่ห้องเก็บอุปกรณ์ข้างห้อง Data Center
2. หยิบ NIC สำรองจากชั้นเก็บอุปกรณ์ ไอเทมเข้าสู่กระเป๋าของผู้เล่น
3. เดินกลับไปที่คอมพิวเตอร์ของครูสาวในห้องพักครู แล้วกด `E` เพื่อเริ่มเปลี่ยนอุปกรณ์

จากนั้นเกมแสดงขั้นตอนต่อไปนี้เป็นภาพเคลื่อนไหวอัตโนมัติ:

1. ปิดเครื่องคอมพิวเตอร์และถอดสายไฟ
2. เปิดฝาเคสคอมพิวเตอร์
3. ถอด Network Interface Card (NIC) ที่มีปัญหา
4. ติดตั้ง Network Interface Card (NIC) ตัวสำรอง
5. ปิดฝาเคส ต่อสาย และเปิดเครื่อง

ผู้เล่นไม่ต้องจัดการน็อต ช่องติดตั้ง Driver หรือรายละเอียดทางช่างระดับลึก เกมเน้นการวิเคราะห์สาเหตุและการเลือกแนวทางแก้ไข

### ช่วงที่ 6: ตรวจสอบหลังแก้ไข

1. ผู้เล่นตรวจดูพอร์ตของ Network Interface Card (NIC) อีกครั้งและพบว่าไฟสถานะติด
2. ผู้เล่นเปิด Command Prompt จำลอง
3. ใช้คำสั่ง `ping` ไปยัง Default Gateway
4. ระบบแสดงผลว่าได้รับการตอบกลับ
5. ผู้เล่นเปิดเว็บไซต์จำลองและพบว่าสามารถเข้าใช้งานได้

## เงื่อนไขสำเร็จ

ภารกิจสำเร็จเมื่อผู้เล่นทำครบทุกข้อ:

- รับสายและเดินทางไปยังห้องพักครู
- ตรวจสอบอาการของคอมพิวเตอร์
- ตรวจสอบสาย LAN ด้วย LAN Cable Tester
- ทดลองสาย LAN เส้นเดิมกับคอมพิวเตอร์อีกเครื่อง
- เลือกเปลี่ยน Network Interface Card (NIC)
- หยิบ NIC สำรองจากห้องเก็บอุปกรณ์และนำไปเปลี่ยน
- ใช้คำสั่ง `ping` ไปยัง Default Gateway สำเร็จ
- เปิดเว็บไซต์จำลองได้
- แจ้งผลให้ครูสาวและกลับไปรายงานหัวหน้างาน Data Center

## บทสนทนาหลังแก้ไข

**ผู้เล่น:**

> ตรวจสอบแล้วพบว่า Network Interface Card มีปัญหาครับ ตอนนี้เปลี่ยนอุปกรณ์และทดสอบการเชื่อมต่อเรียบร้อยแล้ว

**ครูสาว:**

> ขอบคุณค่ะ ตอนนี้ใช้งานอินเทอร์เน็ตได้แล้ว

เมื่อผู้เล่นกลับไปยังห้อง Data Center:

**หัวหน้างาน Data Center:**

> ทำได้ดี คุณตรวจสอบจากสาย LAN ก่อน แล้วจึงใช้หลักฐานตัดสาเหตุจนพบว่า Network Interface Card มีปัญหา

ระบบแสดงข้อความ:

> ภารกิจสำเร็จ: วิเคราะห์และแก้ปัญหาการ์ดเครือข่าย

## ขอบเขตเนื้อหาที่ไม่ใช้ในภารกิจ

- การซ่อมวงจรของ Network Interface Card (NIC)
- การบัดกรีหรือเปลี่ยนชิ้นส่วนอิเล็กทรอนิกส์
- การเลือกช่อง PCI Express
- การติดตั้งหรือแก้ไข Driver ด้วยตนเอง
- การตั้งค่า IP Address, Subnet Mask และ Default Gateway ใหม่
- การ Restart ระบบเครือข่ายส่วนกลางโดยไม่มีหลักฐาน
- การใช้คำสั่งขั้นสูงนอกเหนือจาก `ping`

## สรุปผลการเรียนรู้

ผู้เล่นได้ฝึกแก้ปัญหาอย่างเป็นลำดับ เริ่มจากตรวจสอบอาการ ตรวจสอบสาย LAN ทดลองสลับกับอุปกรณ์ที่ใช้งานได้ และใช้ผลที่พบตัดสาเหตุ ก่อนเลือกเปลี่ยน Network Interface Card (NIC) ที่มีปัญหา จากนั้นตรวจสอบว่าระบบกลับมาใช้งานได้จริง

## รายละเอียดในเกมที่ตกลงกับผู้พัฒนา (12 พ.ย. 2569)

- โทรศัพท์บนโต๊ะผู้เล่นในห้อง IT Support (เครื่องเดียวกับด่าน 6) ใช้ปุ่ม F แทน E
- คอมพิวเตอร์ของครูสาวคือ `STAFF-PC-01` เมื่อคุยกับครูสาวครั้งแรก ครูลุกไปยืนรอข้างโต๊ะ ซ่อมเสร็จแล้วกลับมานั่ง ลองใช้งาน และขอบคุณ
- เครื่องที่ใช้ทดลองสลับสายคือ `STAFF-PC-03` (โต๊ะว่างในห้องพักครู)
- ตรวจสาย: เลือกเครื่องมือจากกระเป๋าช่าง (มีตัวลวง) → LAN Cable Tester แสดงไฟตรงกันครบ → ผู้เล่นตัดสินผลเอง
- อะไหล่อยู่ในกล่องอะไหล่บนโต๊ะกลางห้องเก็บอุปกรณ์ (มีตัวลวง: RAM, การ์ดจอ, USB Wi-Fi)
- เคส PC และการ์ด NIC เป็นโมเดลอย่างง่ายที่สร้างในเกม มีเบราว์เซอร์จำลองสำหรับทดสอบเว็บไซต์
- แท็บติดตามภารกิจมาตรฐาน 11 ขั้นตามลำดับ
