# ด่าน 1 — คำถามเหตุผล (ฉบับใช้ในเกม)

สถานะ: ปรับตามที่ผู้จัดทำขอ (9 พ.ย. 2026) — ไฟล์นี้สร้างจาก `net-sim-3d/missions/mission_01/data/mission_01_reasons.json` ซึ่งเกมใช้จริง

## รูปแบบ

- จุดติดตั้ง 3 จุด จุดละ 4 อุปกรณ์ (ถูก 1 ลวง 3) แสดงเป็นการ์ดมีรูปและชื่อ
- **คลิกอุปกรณ์ = เลือกอุปกรณ์นั้น** แล้วตอบว่า "เลือก ... เพราะ…" จาก 4 ตัวเลือก (ไม่มีปุ่ม "ไม่เลือก" และไม่ต้องกรอกจำนวน)
- อุปกรณ์ที่ถูก: เหตุผลถูก 1 ข้อ ✅ + ตัวลวง 3 ข้อ | อุปกรณ์ลวง: ทั้ง 4 ข้อเป็นความเข้าใจผิด (เลือกอุปกรณ์ลวงถือว่าผิดอยู่แล้ว ข้อที่เลือกบอกว่าเข้าใจผิดเรื่องอะไร)
- ตัวเลือกยาวใกล้เคียงกัน (ข้อยาวสุดไม่เกิน 1.5 เท่าของข้อสั้นสุด) และสลับลำดับทุกครั้ง
- วงเล็บ *ความเข้าใจผิด: …* เป็นหมายเหตุสำหรับผู้จัดทำ แสดงในหน้าสรุปผล ไม่แสดงตอนเลือก
- Repeater และ Bridge ไม่มีในหนังสือ แต่ผู้จัดทำอนุญาตให้ใช้

## จุดที่ 1 · เชื่อมต่อเครือข่ายภายนอกกับเครือข่ายภายใน

### Router ✅ (อุปกรณ์ที่ถูก)

"เลือก Router เพราะ…"

- ก) เชื่อมเครือข่ายภายในห้องเข้ากับเครือข่ายภายนอก และหาเส้นทางส่งข้อมูลระหว่างสองเครือข่าย ✅
- ข) กระจายสัญญาณไร้สายให้คอมพิวเตอร์ทุกเครื่องในห้องเชื่อมต่ออินเทอร์เน็ตได้พร้อมกัน *(ความเข้าใจผิด: Router คืออุปกรณ์กระจาย Wi-Fi)*
- ค) มีพอร์ตมากพอให้ต่อคอมพิวเตอร์ทั้ง 21 เครื่องเข้ากับอุปกรณ์ตัวนี้ได้โดยตรง *(ความเข้าใจผิด: Router ทำหน้าที่อุปกรณ์ศูนย์กลางของห้อง)*
- ง) ขยายสัญญาณที่อ่อนลงจากสายยาวให้แรงขึ้นก่อนส่งต่อไปยังคอมพิวเตอร์ในห้อง *(ความเข้าใจผิด: สับสน Router กับ Repeater)*

### Wireless Access Point (ตัวลวง)

"เลือก Wireless Access Point เพราะ…"

- ก) มีเสาสัญญาณในตัว จึงรับอินเทอร์เน็ตจากผู้ให้บริการภายนอกได้โดยตรงไม่ต้องใช้สาย *(ความเข้าใจผิด: มีเสาสัญญาณแปลว่าเชื่อมเครือข่ายภายนอกได้)*
- ข) ทำงานเหมือน Router ทุกประการ เพียงแต่ส่งข้อมูลระหว่างเครือข่ายผ่านคลื่นวิทยุแทนสาย *(ความเข้าใจผิด: Access Point คือ Router แบบไร้สาย)*
- ค) ส่งข้อมูลไร้สายได้เร็วกว่าสาย LAN จึงเหมาะเป็นทางเชื่อมหลักออกสู่เครือข่ายภายนอก *(ความเข้าใจผิด: เครือข่ายไร้สายเร็วกว่าเครือข่ายแบบใช้สายเสมอ)*
- ง) ทุกเครือข่ายในโรงเรียนต้องผ่านจุดกระจาย Wi-Fi ก่อน จึงจะออกสู่อินเทอร์เน็ตได้ *(ความเข้าใจผิด: Wi-Fi เป็นทางออกอินเทอร์เน็ตทางเดียว)*

### Switched Hub 24 Port (ตัวลวง)

"เลือก Switched Hub 24 Port เพราะ…"

- ก) มีจำนวนพอร์ตมากที่สุด จึงรองรับการเชื่อมต่อได้ทุกเครือข่ายทั้งภายในและภายนอก *(ความเข้าใจผิด: พอร์ตมากแปลว่าเชื่อมได้ทุกเครือข่าย)*
- ข) ส่งข้อมูลถึงเครื่องปลายทางในห้องได้ถูกต้อง จึงส่งต่อไปถึงเครือข่ายภายนอกได้เช่นกัน *(ความเข้าใจผิด: Switched Hub ทำหน้าที่ Router ได้)*
- ค) อุปกรณ์ที่ติดตั้งอยู่ใน Wall Rack ทุกตัวทำหน้าที่เชื่อมต่อกับเครือข่ายภายนอกได้ *(ความเข้าใจผิด: ตำแหน่งติดตั้งเป็นตัวกำหนดหน้าที่)*
- ง) ส่งข้อมูลเฉพาะเครื่องปลายทาง จึงปลอดภัยพอที่จะใช้เป็นทางเข้าออกของเครือข่าย *(ความเข้าใจผิด: ความปลอดภัยเป็นตัวกำหนดหน้าที่เชื่อมเครือข่ายภายนอก)*

### Repeater (ตัวลวง)

"เลือก Repeater เพราะ…"

- ก) ขยายสัญญาณให้ส่งได้ไกลขึ้น จึงส่งข้อมูลไปถึงเครือข่ายภายนอกที่อยู่ไกลได้ *(ความเข้าใจผิด: ส่งได้ไกลแปลว่าเชื่อมเครือข่ายภายนอกได้)*
- ข) เป็นอุปกรณ์ที่ใช้เชื่อมเครือข่ายทุกแบบเข้าด้วยกัน โดยไม่ต้องกำหนดเส้นทางข้อมูล *(ความเข้าใจผิด: Repeater ทำหน้าที่ Router)*
- ค) ทำงานเหมือน Router ทุกอย่างแต่มีราคาถูกกว่า จึงคุ้มค่ากว่าสำหรับห้องเรียน *(ความเข้าใจผิด: Repeater กับ Router ต่างกันแค่ราคา)*
- ง) ทวนสัญญาณซ้ำ ทำให้ข้อมูลจากอินเทอร์เน็ตไม่สูญหายระหว่างทางเข้าห้องคอม *(ความเข้าใจผิด: Repeater ทำหน้าที่ป้องกันข้อมูลสูญหาย)*

## จุดที่ 2 · อุปกรณ์ศูนย์กลางภายใน Wall Rack สำหรับ 21 เครื่อง

### Switched Hub 24 Port ✅ (อุปกรณ์ที่ถูก)

"เลือก Switched Hub 24 Port เพราะ…"

- ก) ส่งข้อมูลไปเฉพาะพอร์ตปลายทาง และมีพอร์ตพอสำหรับ 21 เครื่องรวมกับ Router และ Access Point ✅
- ข) ส่งข้อมูลออกไปทุกพอร์ตพร้อมกัน ทำให้คอมพิวเตอร์ทุกเครื่องได้รับข้อมูลเร็วขึ้น *(ความเข้าใจผิด: สับสนการทำงานของ Switched Hub กับ Shared Hub)*
- ค) เชื่อมต่อออกอินเทอร์เน็ตได้ด้วยตัวเอง จึงไม่จำเป็นต้องมี Router อยู่ในห้องนี้อีก *(ความเข้าใจผิด: Switched Hub ทำหน้าที่ Router ได้)*
- ง) มีพอร์ตเท่ากับจำนวนคอมพิวเตอร์ในห้องพอดี จึงไม่เหลือพอร์ตว่างให้สิ้นเปลือง *(ความเข้าใจผิด: ลืมนับพอร์ตที่ต่อไป Router และ Access Point)*

### Shared Hub 24 Port (ตัวลวง)

"เลือก Shared Hub 24 Port เพราะ…"

- ก) มีพอร์ตเท่ากับ Switched Hub 24 Port จึงใช้แทนกันได้โดยไม่มีผลต่อการทำงาน *(ความเข้าใจผิด: เลือกอุปกรณ์จากจำนวนพอร์ตอย่างเดียว)*
- ข) ส่งข้อมูลไปทุกเครื่องพร้อมกัน ทำให้คอมพิวเตอร์ทุกเครื่องได้รับข้อมูลครบเสมอ *(ความเข้าใจผิด: การส่งข้อมูลไปทุกพอร์ตเป็นข้อดี)*
- ค) Shared Hub กับ Switched Hub เป็นอุปกรณ์ชนิดเดียวกัน เพียงแต่ใช้ชื่อเรียกต่างกัน *(ความเข้าใจผิด: Shared Hub กับ Switched Hub ทำงานเหมือนกัน)*
- ง) ราคาถูกกว่าและเร็วพอ แม้คอมพิวเตอร์ทั้ง 21 เครื่องจะใช้งานพร้อมกันทั้งห้อง *(ความเข้าใจผิด: Shared Hub รองรับการใช้งานพร้อมกันจำนวนมากได้ดี)*

### Switched Hub 16 Port (ตัวลวง)

"เลือก Switched Hub 16 Port เพราะ…"

- ก) เสียบคอมพิวเตอร์ 2 เครื่องในพอร์ตเดียวกันได้ จึงรองรับได้ครบทั้ง 21 เครื่อง *(ความเข้าใจผิด: 1 พอร์ตต่อคอมพิวเตอร์ได้หลายเครื่อง)*
- ข) จำนวนพอร์ตน้อยกว่าทำให้แต่ละพอร์ตได้ความเร็วมากขึ้น เครือข่ายจึงเร็วกว่าเดิม *(ความเข้าใจผิด: พอร์ตน้อยแปลว่าเร็วกว่า)*
- ค) คอมพิวเตอร์ที่เหลือเชื่อมต่อผ่าน Wi-Fi แทนได้ จำนวนพอร์ตจึงไม่ใช่เรื่องสำคัญ *(ความเข้าใจผิด: ไม่ทำตามข้อกำหนดที่ให้คอมพิวเตอร์ทุกเครื่องใช้สาย)*
- ง) ส่งข้อมูลเฉพาะพอร์ตปลายทางเหมือนรุ่น 24 พอร์ต จึงใช้แทนกันได้ในทุกกรณี *(ความเข้าใจผิด: ไม่นับจำนวนพอร์ตที่ต้องใช้)*

### Switched Hub 8 Port (ตัวลวง)

"เลือก Switched Hub 8 Port เพราะ…"

- ก) ซื้อเพียงตัวเดียวก็ต่อคอมพิวเตอร์ได้ไม่จำกัดจำนวน เพราะส่งข้อมูลเฉพาะปลายทาง *(ความเข้าใจผิด: ไม่เข้าใจข้อจำกัดของจำนวนพอร์ต)*
- ข) หนึ่งพอร์ตต่อคอมพิวเตอร์ได้หลายเครื่อง จึงรองรับคอมพิวเตอร์ทั้งห้องได้สบาย *(ความเข้าใจผิด: 1 พอร์ตต่อคอมพิวเตอร์ได้หลายเครื่อง)*
- ค) ขนาดเล็กและใช้ไฟน้อย จึงเหมาะกับห้องเรียนมากกว่ารุ่นที่มีพอร์ตจำนวนมาก *(ความเข้าใจผิด: เลือกอุปกรณ์จากเกณฑ์ที่ไม่เกี่ยวกับความต้องการ)*
- ง) พอร์ตน้อยทำให้ดูแลง่าย ถ้าเครื่องไหนเสียก็หาสาเหตุได้เร็วกว่ารุ่นอื่น *(ความเข้าใจผิด: เลือกอุปกรณ์จากความสะดวกในการดูแลแทนความต้องการของห้อง)*

## จุดที่ 3 · ให้บริการเครือข่ายไร้สายภายในห้อง

### Wireless Access Point ✅ (อุปกรณ์ที่ถูก)

"เลือก Wireless Access Point เพราะ…"

- ก) รับสาย LAN จากอุปกรณ์ศูนย์กลาง แล้วกระจายสัญญาณให้อุปกรณ์พกพาเข้าเครือข่ายของห้อง ✅
- ข) เชื่อมต่อเครือข่ายภายในเข้ากับเครือข่ายภายนอกได้เองโดยไม่ต้องผ่าน Router *(ความเข้าใจผิด: Access Point ทำหน้าที่ Router)*
- ค) เพิ่มจำนวนพอร์ตสาย LAN ให้คอมพิวเตอร์ในห้องที่ต่อกับอุปกรณ์ศูนย์กลางไม่ทัน *(ความเข้าใจผิด: Access Point ทำหน้าที่ Switched Hub)*
- ง) ขยายสัญญาณ Wi-Fi จากห้องอื่นให้แรงขึ้น โดยไม่ต้องต่อสาย LAN เข้ากับเครือข่าย *(ความเข้าใจผิด: Access Point คือตัวขยายสัญญาณ)*

### Router (ตัวลวง)

"เลือก Router เพราะ…"

- ก) สัญญาณ Wi-Fi ทุกชนิดต้องมาจาก Router จึงต้องติดตั้ง Router เพิ่มอีกตัวในจุดนี้ *(ความเข้าใจผิด: สัญญาณ Wi-Fi มาจาก Router เท่านั้น)*
- ข) Router กับ Access Point ทำงานเหมือนกันทุกอย่าง จะเลือกตัวไหนก็ได้ผลเหมือนกัน *(ความเข้าใจผิด: Access Point คือ Router แบบไร้สาย)*
- ค) ติดตั้ง Router หลายตัวในห้องเดียวกันจะช่วยให้อินเทอร์เน็ตทั้งห้องเร็วขึ้น *(ความเข้าใจผิด: จำนวน Router เพิ่มความเร็วอินเทอร์เน็ต)*
- ง) Router แยกอุปกรณ์พกพาไว้คนละเครือข่ายกับคอมพิวเตอร์ ซึ่งเป็นสิ่งที่ห้องต้องการ *(ความเข้าใจผิด: อ่านข้อกำหนดผิดว่าต้องแยกเครือข่ายของอุปกรณ์พกพา)*

### Switched Hub 8 Port (ตัวลวง)

"เลือก Switched Hub 8 Port เพราะ…"

- ก) อุปกรณ์เครือข่ายทุกชนิดปล่อยสัญญาณไร้สายได้ เพียงต่อสาย LAN เข้ากับเครือข่าย *(ความเข้าใจผิด: อุปกรณ์เครือข่ายทุกตัวมี Wi-Fi)*
- ข) ต่อเพิ่มจากอุปกรณ์ศูนย์กลางแล้ว อุปกรณ์พกพาจะเชื่อมต่อเข้าเครือข่ายได้เอง *(ความเข้าใจผิด: ต่อสาย LAN แล้วจะได้ Wi-Fi เอง)*
- ค) ขนาดเล็กและน้ำหนักเบา จึงเหมาะติดตั้งบนเพดานเพื่อกระจายสัญญาณให้ทั่วห้อง *(ความเข้าใจผิด: ขนาดอุปกรณ์เป็นตัวกำหนดหน้าที่)*
- ง) มีพอร์ตว่างพอให้อุปกรณ์พกพาทุกเครื่องในห้องเสียบสายเข้าใช้งานเครือข่ายได้ *(ความเข้าใจผิด: อุปกรณ์พกพาต้องใช้สาย LAN)*

### Bridge (ตัวลวง)

"เลือก Bridge เพราะ…"

- ก) Bridge แปลว่าสะพาน จึงเป็นทางเชื่อมให้อุปกรณ์พกพาทุกเครื่องเข้าเครือข่ายได้ *(ความเข้าใจผิด: เดาหน้าที่จากความหมายของชื่ออุปกรณ์)*
- ข) Bridge กับ Access Point เป็นอุปกรณ์ชนิดเดียวกัน เพียงแต่ผู้ผลิตตั้งชื่อต่างกัน *(ความเข้าใจผิด: สับสน Bridge กับ Access Point)*
- ค) Bridge ขยายสัญญาณ Wi-Fi จากอุปกรณ์ศูนย์กลางให้ครอบคลุมทั่วทั้งห้องได้ *(ความเข้าใจผิด: Bridge ทำหน้าที่ขยายสัญญาณ)*
