# ด่าน 1 — ร่างคำถามเหตุผล (รอผู้จัดทำตรวจ)

สถานะ: **ผู้จัดทำอนุมัติแล้ว (9 พ.ย. 2026)** ใส่ในเกมที่ `net-sim-3d/missions/mission_01/data/mission_01_reasons.json`
(Repeater และ Bridge ไม่มีในหนังสือ แต่ผู้จัดทำอนุญาตให้ใช้)

## โครงสร้าง

- จุดติดตั้ง 3 จุด จุดละ 4 อุปกรณ์ (ถูก 1 + ตัวลวง 3)
- คลิกอุปกรณ์ → เลือก **[เลือกอุปกรณ์นี้]** หรือ **[ไม่เลือกอุปกรณ์นี้]** → ตอบคำถามเหตุผลแบบปรนัย 3 ตัวเลือก
- อุปกรณ์ทุกตัวมี 2 คำถาม (ฝั่งเลือก / ฝั่งไม่เลือก) ถามเฉพาะตัวที่ผู้เล่นคลิก
- **ฝั่งที่ตัดสินใจถูก** (เลือกตัวที่ถูก / ไม่เลือกตัวลวง): มีเหตุผลที่ถูก 1 ข้อ ✅ และตัวลวง 2 ข้อที่มาจากความเข้าใจผิด
- **ฝั่งที่ตัดสินใจผิด** (ไม่เลือกตัวที่ถูก / เลือกตัวลวง): ทั้ง 3 ข้อเป็นความเข้าใจผิด การตัดสินใจนี้นับว่าผิดอยู่แล้ว
  แต่ข้อที่ผู้เรียนเลือกบอกได้ว่าเข้าใจผิดเรื่องอะไร ใช้แสดงในหน้าสรุปและเก็บเป็นข้อมูลให้ผู้สอน
- ในเกมจะสลับลำดับตัวเลือกทุกครั้ง (ก ข ค ในเอกสารนี้ไม่ใช่ลำดับจริง)
- วงเล็บ *ความเข้าใจผิด: …* เป็นหมายเหตุสำหรับผู้จัดทำ ไม่แสดงในเกม

## จุดที่ 1 · เชื่อมต่อเครือข่ายภายนอกกับเครือข่ายภายใน

ตัวเลือก: **Router** ✅ · Wireless Access Point · Switched Hub 24 Port · Repeater

### Router (อุปกรณ์ที่ถูก)

**ฝั่งเลือก — "เลือก Router เพราะ…"**
- ก) เชื่อมเครือข่ายต่างวงเข้าด้วยกัน และหาเส้นทางส่งข้อมูลระหว่างเครือข่ายภายในห้องกับเครือข่ายภายนอก ✅
- ข) กระจายสัญญาณไร้สายให้คอมพิวเตอร์ทุกเครื่องในห้อง *(ความเข้าใจผิด: Router คือ Wi-Fi)*
- ค) มีพอร์ตมากพอสำหรับต่อคอมพิวเตอร์ทั้ง 21 เครื่องโดยตรง *(ความเข้าใจผิด: Router ทำหน้าที่อุปกรณ์ศูนย์กลาง)*

**ฝั่งไม่เลือก — "ไม่เลือก Router เพราะ…"** (ตัดสินใจผิด)
- ก) Router ใช้ได้เฉพาะกับเครือข่ายไร้สาย *(ความเข้าใจผิด: Router คือ Wi-Fi)*
- ข) Switched Hub ส่งข้อมูลออกสู่เครือข่ายภายนอกได้เองอยู่แล้ว *(ความเข้าใจผิด: Switch ทำหน้าที่ Router)*
- ค) Router ใช้เชื่อมคอมพิวเตอร์ที่อยู่ในห้องเดียวกันเท่านั้น *(ความเข้าใจผิด: สับสนหน้าที่ภายใน/ภายนอก)*

### Wireless Access Point (ตัวลวง)

**ฝั่งไม่เลือก — "ไม่เลือก Wireless Access Point เพราะ…"**
- ก) ทำหน้าที่ให้อุปกรณ์ไร้สายเข้าสู่เครือข่ายภายใน ไม่ได้เชื่อมเครือข่ายต่างวงหรือหาเส้นทางไปเครือข่ายภายนอก ✅
- ข) สัญญาณไร้สายไม่สามารถส่งข้อมูลอินเทอร์เน็ตได้ *(ความเข้าใจผิด: ไร้สาย = ใช้อินเทอร์เน็ตไม่ได้)*
- ค) ใช้ได้กับโทรศัพท์มือถือเท่านั้น ใช้กับคอมพิวเตอร์ไม่ได้ *(ความเข้าใจผิด: จำกัดชนิดอุปกรณ์)*

**ฝั่งเลือก — "เลือก Wireless Access Point เพราะ…"** (ตัดสินใจผิด)
- ก) มีเสาสัญญาณ จึงรับอินเทอร์เน็ตจากภายนอกได้โดยตรง *(ความเข้าใจผิด: เสาสัญญาณ = เชื่อมภายนอก)*
- ข) ทำงานเหมือน Router ทุกประการ เพียงแต่ไม่ใช้สาย *(ความเข้าใจผิด: AP = Router ไร้สาย)*
- ค) อุปกรณ์ไร้สายส่งข้อมูลได้เร็วกว่า จึงเหมาะกับจุดเชื่อมต่อภายนอก *(ความเข้าใจผิด: ไร้สายเร็วกว่าสาย)*

### Switched Hub 24 Port (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) ส่งข้อมูลระหว่างเครื่องในเครือข่ายเดียวกัน ไม่ได้เชื่อมต่อและหาเส้นทางไปยังเครือข่ายภายนอก ✅
- ข) มีพอร์ตไม่พอสำหรับเชื่อมต่อเครือข่ายภายนอก *(ความเข้าใจผิด: หน้าที่ขึ้นกับจำนวนพอร์ต)*
- ค) ส่งข้อมูลได้ช้ากว่า Router จึงใช้กับอินเทอร์เน็ตไม่ได้ *(ความเข้าใจผิด: ความเร็วเป็นตัวกำหนดหน้าที่)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) มีพอร์ตมากที่สุด จึงเชื่อมต่อได้ทุกเครือข่าย *(ความเข้าใจผิด: พอร์ตมาก = เชื่อมได้ทุกอย่าง)*
- ข) ส่งข้อมูลถึงเครื่องปลายทางในห้องได้ จึงส่งไปถึงอินเทอร์เน็ตได้เช่นกัน *(ความเข้าใจผิด: Switch ทำหน้าที่ Router)*
- ค) อุปกรณ์ที่ติดตั้งใน Wall Rack ทุกตัวเชื่อมเครือข่ายภายนอกได้ *(ความเข้าใจผิด: ตำแหน่งกำหนดหน้าที่)*

### Repeater (ตัวลวง) — *โปรดตรวจว่าหนังสือใช้คำนี้*

**ฝั่งไม่เลือก**
- ก) ทำหน้าที่ทวนสัญญาณให้ส่งได้ไกลขึ้นภายในเครือข่ายเดิม ไม่ได้เชื่อมเครือข่ายต่างวงเข้าด้วยกัน ✅
- ข) ทำให้สัญญาณอ่อนลง จึงไม่ควรใช้ในเครือข่าย *(ความเข้าใจผิด: หน้าที่กลับกัน)*
- ค) ใช้ได้กับสายโทรศัพท์เท่านั้น *(ความเข้าใจผิด: ชนิดสื่อ)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) ขยายสัญญาณให้ไปถึงเครือข่ายภายนอกที่อยู่ไกลได้ *(ความเข้าใจผิด: ระยะทาง = ภายนอก)*
- ข) เป็นอุปกรณ์ที่เชื่อมทุกเครือข่ายเข้าด้วยกัน *(ความเข้าใจผิด: Repeater = Router)*
- ค) ทำงานเหมือน Router แต่ราคาถูกกว่า *(ความเข้าใจผิด: ต่างกันแค่ราคา)*

## จุดที่ 2 · อุปกรณ์ศูนย์กลางภายใน Wall Rack สำหรับ 21 เครื่อง

ตัวเลือก: **Switched Hub 24 Port** ✅ · Shared Hub 24 Port · Switched Hub 16 Port · Switched Hub 8 Port

หมายเหตุการคำนวณพอร์ต: คอมพิวเตอร์ 21 + สายไป Router 1 + สายไป Wireless Access Point 1 = 23 พอร์ต จึงต้องใช้ 24 พอร์ต

### Switched Hub 24 Port (อุปกรณ์ที่ถูก)

**ฝั่งเลือก**
- ก) ส่งข้อมูลไปเฉพาะพอร์ตของเครื่องปลายทาง และมีพอร์ตพอสำหรับ 21 เครื่องรวมกับพอร์ตที่ต่อไป Router และ Wireless Access Point ✅
- ข) ส่งข้อมูลไปทุกพอร์ตพร้อมกัน ทุกเครื่องจึงได้รับข้อมูลเร็วขึ้น *(ความเข้าใจผิด: สับสนกับ Shared Hub)*
- ค) เชื่อมต่ออินเทอร์เน็ตได้เองโดยไม่ต้องมี Router *(ความเข้าใจผิด: Switch ทำหน้าที่ Router)*

**ฝั่งไม่เลือก** (ตัดสินใจผิด)
- ก) 24 พอร์ตมากเกินไป ควรใช้รุ่นที่พอร์ตเท่ากับจำนวนเครื่องพอดี *(ความเข้าใจผิด: ลืมนับพอร์ตต่อ Router/AP)*
- ข) Shared Hub ทำงานเหมือนกันแต่ราคาถูกกว่า *(ความเข้าใจผิด: Hub = Switch)*
- ค) การต่อเครื่องจำนวนมากต้องใช้ Router แทน *(ความเข้าใจผิด: Router เป็นศูนย์กลาง)*

### Shared Hub 24 Port (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) ส่งข้อมูลที่เข้ามาออกไปทุกพอร์ต ทำให้ข้อมูลชนกันและเครือข่ายช้าเมื่อหลายเครื่องใช้งานพร้อมกัน ✅
- ข) มีพอร์ตไม่พอสำหรับ 21 เครื่อง *(ความเข้าใจผิด: อ่านจำนวนพอร์ตผิด)*
- ค) ต่อเข้ากับ Router ไม่ได้ *(ความเข้าใจผิด: Hub เชื่อมกับ Router ไม่ได้)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) มีพอร์ตเท่ากัน จึงใช้แทน Switched Hub ได้ *(ความเข้าใจผิด: ดูแค่จำนวนพอร์ต)*
- ข) ส่งข้อมูลไปทุกเครื่องพร้อมกัน ทุกเครื่องจึงได้รับข้อมูลครบ *(ความเข้าใจผิด: Broadcast เป็นข้อดี)*
- ค) Shared Hub กับ Switched Hub เป็นอุปกรณ์ชนิดเดียวกัน ต่างกันแค่ชื่อ *(ความเข้าใจผิด: Hub = Switch)*

### Switched Hub 16 Port (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) มีพอร์ตไม่พอสำหรับคอมพิวเตอร์ 21 เครื่องรวมกับพอร์ตที่ต้องต่อ Router และ Wireless Access Point ✅
- ข) ส่งข้อมูลไปทุกพอร์ตเหมือน Shared Hub *(ความเข้าใจผิด: จำนวนพอร์ตเปลี่ยนวิธีส่งข้อมูล)*
- ค) ใช้ได้เฉพาะกับเครือข่ายไร้สาย *(ความเข้าใจผิด: สับสนชนิดอุปกรณ์)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) เสียบคอมพิวเตอร์ 2 เครื่องในพอร์ตเดียวกันได้ *(ความเข้าใจผิด: 1 พอร์ตต่อได้หลายเครื่อง)*
- ข) พอร์ตน้อยกว่าทำให้ส่งข้อมูลได้เร็วกว่า *(ความเข้าใจผิด: พอร์ตน้อย = เร็ว)*
- ค) เครื่องที่เหลือใช้ Wi-Fi แทนได้ จำนวนพอร์ตจึงไม่สำคัญ *(ความเข้าใจผิด: เลี่ยงข้อกำหนดที่ให้ใช้สาย)*

### Switched Hub 8 Port (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) มีเพียง 8 พอร์ต ต่อคอมพิวเตอร์ 21 เครื่องไม่ได้ ✅
- ข) ทำงานช้ากว่าเพราะเป็นรุ่นเก่า *(ความเข้าใจผิด: พอร์ตน้อย = รุ่นเก่า/ช้า)*
- ค) ใช้ได้เฉพาะในบ้าน ห้ามใช้ในโรงเรียน *(ความเข้าใจผิด: กฎที่ไม่มีอยู่จริง)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) ซื้อ 1 ตัวแล้วต่อคอมพิวเตอร์ได้ไม่จำกัดจำนวน *(ความเข้าใจผิด: ไม่เข้าใจข้อจำกัดของพอร์ต)*
- ข) 1 พอร์ตต่อคอมพิวเตอร์ได้หลายเครื่อง *(ความเข้าใจผิด: 1 พอร์ตต่อได้หลายเครื่อง)*
- ค) ขนาดเล็กและประหยัดไฟ จึงเหมาะกับห้องเรียน *(ความเข้าใจผิด: ใช้เกณฑ์ที่ไม่เกี่ยวกับความต้องการ)*

## จุดที่ 3 · ให้บริการเครือข่ายไร้สายภายในห้อง

ตัวเลือก: **Wireless Access Point** ✅ · Router · Switched Hub 8 Port · Bridge

### Wireless Access Point (อุปกรณ์ที่ถูก)

**ฝั่งเลือก**
- ก) รับสาย LAN จากอุปกรณ์ศูนย์กลาง แล้วกระจายสัญญาณไร้สายให้อุปกรณ์พกพาเข้าสู่เครือข่ายเดียวกับห้องได้ ✅
- ข) ทำหน้าที่เชื่อมเครือข่ายภายนอกแทน Router ได้ *(ความเข้าใจผิด: AP = Router)*
- ค) เพิ่มจำนวนพอร์ตสาย LAN ให้คอมพิวเตอร์ในห้อง *(ความเข้าใจผิด: AP = Switch)*

**ฝั่งไม่เลือก** (ตัดสินใจผิด)
- ก) อุปกรณ์ไร้สายต้องเชื่อมต่อผ่าน Router เสมอ จึงใช้ Access Point ไม่ได้ *(ความเข้าใจผิด: Wi-Fi มาจาก Router เท่านั้น)*
- ข) Access Point ใช้ได้เฉพาะภายนอกอาคาร *(ความเข้าใจผิด: สถานที่ติดตั้ง)*
- ค) Wi-Fi ทำให้เครือข่ายแบบใช้สายช้าลง จึงไม่ควรติดตั้ง *(ความเข้าใจผิด: ไร้สายรบกวนเครือข่ายสาย)*

### Router (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) ห้องนี้มี Router เชื่อมเครือข่ายภายนอกอยู่แล้ว จุดนี้ต้องการเพียงให้อุปกรณ์พกพาเข้าสู่เครือข่ายภายในเดิม การติดตั้ง Router เพิ่มจะแยกเป็นเครือข่ายอีกวง ✅
- ข) Router ทุกรุ่นไม่มีเสาสัญญาณ จึงให้บริการไร้สายไม่ได้ *(ความเข้าใจผิด: เหมารวมทุกรุ่น)*
- ค) Router ใช้ได้กับคอมพิวเตอร์ตั้งโต๊ะเท่านั้น *(ความเข้าใจผิด: จำกัดชนิดอุปกรณ์)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) สัญญาณ Wi-Fi ทุกชนิดต้องมาจาก Router *(ความเข้าใจผิด: Wi-Fi = Router)*
- ข) Router กับ Access Point ทำงานเหมือนกันทุกอย่าง *(ความเข้าใจผิด: AP = Router)*
- ค) ติดตั้ง Router หลายตัวทำให้อินเทอร์เน็ตเร็วขึ้น *(ความเข้าใจผิด: จำนวน Router = ความเร็ว)*

### Switched Hub 8 Port (ตัวลวง)

**ฝั่งไม่เลือก**
- ก) เชื่อมต่อได้เฉพาะอุปกรณ์ที่ใช้สาย LAN ไม่ได้กระจายสัญญาณไร้สาย ✅
- ข) มีพอร์ตน้อยเกินไปสำหรับ Wi-Fi *(ความเข้าใจผิด: Wi-Fi ใช้พอร์ต)*
- ค) ติดตั้งบนเพดานไม่ได้ *(ความเข้าใจผิด: ใช้ตำแหน่งแทนหน้าที่)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) อุปกรณ์เครือข่ายทุกชนิดปล่อยสัญญาณไร้สายได้ *(ความเข้าใจผิด: อุปกรณ์ทุกตัวมี Wi-Fi)*
- ข) ต่อเพิ่มจากอุปกรณ์ศูนย์กลางแล้ว อุปกรณ์พกพาจะเชื่อมต่อได้เอง *(ความเข้าใจผิด: ต่อสายแล้วได้ Wi-Fi)*
- ค) ขนาดเล็กจึงเหมาะติดบนเพดานเพื่อกระจาย Wi-Fi *(ความเข้าใจผิด: ขนาดกำหนดหน้าที่)*

### Bridge (ตัวลวง) — *โปรดตรวจว่าหนังสือใช้คำนี้*

**ฝั่งไม่เลือก**
- ก) ใช้เชื่อมเครือข่าย LAN สองส่วนเข้าด้วยกันและกรองข้อมูลระหว่างส่วน ไม่ได้ทำหน้าที่ให้อุปกรณ์ไร้สายเข้าสู่เครือข่าย ✅
- ข) Bridge ใช้ได้กับเครือข่ายภายนอกเท่านั้น *(ความเข้าใจผิด: สับสนกับ Router)*
- ค) Bridge ทำให้สัญญาณอ่อนลง *(ความเข้าใจผิด: หน้าที่กลับกัน)*

**ฝั่งเลือก** (ตัดสินใจผิด)
- ก) Bridge แปลว่าสะพาน จึงเชื่อมอุปกรณ์พกพาทุกเครื่องเข้าเครือข่ายได้ *(ความเข้าใจผิด: เดาจากความหมายของชื่อ)*
- ข) Bridge กับ Access Point คืออุปกรณ์เดียวกัน *(ความเข้าใจผิด: สับสนชนิดอุปกรณ์)*
- ค) Bridge ขยายสัญญาณ Wi-Fi ให้ทั่วห้อง *(ความเข้าใจผิด: Bridge = ตัวขยายสัญญาณ)*
