# ภารกิจที่ 6: ช่วยเหลือผู้ใช้ด้วยซอฟต์แวร์ควบคุมเครื่องระยะไกล

## หัวข้อบทเรียน

ซอฟต์แวร์ควบคุมเครื่องคอมพิวเตอร์ระยะไกล โดยเน้นหลักการเชื่อมต่อ การยืนยันสิทธิ์ และความสามารถในการมองเห็นและควบคุมเครื่องปลายทาง

## แนวคิดของภารกิจ

ในกรณีที่ผู้ดูแลระบบไม่สะดวกเดินทางไปยังเครื่องที่มีปัญหา สามารถใช้ซอฟต์แวร์ควบคุมเครื่องระยะไกลเพื่อตรวจสอบและแก้ไขปัญหาด้านซอฟต์แวร์เบื้องต้นได้

ภารกิจใช้ TeamViewer เป็นโปรแกรมหลัก ผู้เล่นต้องรับ TeamViewer ID และ Password จากครูสาว แล้วพิมพ์ข้อมูลทั้งสองรายการด้วยตนเอง เมื่อเชื่อมต่อสำเร็จ ผู้เล่นจะเห็น Desktop ของเครื่องครูสาวและสามารถใช้เมาส์ควบคุมเครื่องปลายทางได้

ปัญหาที่กำหนดให้แก้เป็นปัญหาง่าย คือเสียงของเครื่องครูสาวถูกตั้งเป็น Mute เพื่อให้ภารกิจเน้นความสามารถของซอฟต์แวร์ควบคุมระยะไกล ไม่เปลี่ยนไปเป็นการวัดความรู้ด้านอื่น

## ความสอดคล้องกับหนังสือบทที่ 8

หนังสือกล่าวถึง TeamViewer และ AnyDesk เป็นตัวอย่างซอฟต์แวร์ควบคุมเครื่องคอมพิวเตอร์ระยะไกล

หลักการเชื่อมต่อตามหนังสือ:

- TeamViewer: เปิดโปรแกรมพร้อมกันทั้งสองเครื่อง ใช้ TeamViewer ID และ Password ของเครื่องปลายทางในการเชื่อมต่อ
- AnyDesk: เปิดโปรแกรมพร้อมกันทั้งสองเครื่อง ใช้ AnyDesk Address ของเครื่องปลายทาง แล้วให้ผู้ใช้ปลายทางกด Accept

ขั้นตอนที่หนังสืออธิบายไม่ได้กำหนดให้ผู้ใช้กรอก IP Address โดยตรง ภารกิจจึงไม่ใช้ IP Address เป็นข้อมูลสำหรับเข้าสู่ Remote Session

AnyDesk แสดงเป็นความรู้เปรียบเทียบในหน้าสรุป แต่ไม่สร้างการเชื่อมต่อซ้ำในภารกิจ เพราะเกมเพลย์จะเหมือนกับ TeamViewer มากเกินไป

## สถานที่ดำเนินภารกิจ

1. ห้อง Data Center: ตำแหน่งของผู้เล่นและคอมพิวเตอร์ที่ใช้เชื่อมต่อ
2. ห้องพักครู: ตำแหน่งของครูสาวและคอมพิวเตอร์ปลายทาง

ผู้เล่นไม่ต้องเดินทางออกจากห้อง Data Center ระหว่างดำเนินภารกิจ

## ตัวละครที่เกี่ยวข้อง

- ผู้เล่น: เจ้าหน้าที่ IT Support
- ครูสาว: ผู้ใช้เครื่องปลายทางและผู้ขอรับความช่วยเหลือ
- หัวหน้างาน Data Center: ผู้มอบหมายให้ผู้เล่นช่วยเหลือจากระยะไกล

## เนื้อเรื่อง

ขณะที่ผู้เล่นกำลังเฝ้าตรวจสอบระบบอยู่ในห้อง Data Center ครูสาวจากห้องพักครูโทรมาแจ้งว่าเปิดวิดีโอประกอบการสอนแล้วไม่ได้ยินเสียง

ผู้เล่นไม่สะดวกเดินทางออกจากห้อง Data Center เพราะต้องเฝ้าระบบอยู่ หัวหน้างานจึงให้ผู้เล่นใช้ TeamViewer ตรวจสอบเครื่องของครูสาวจากระยะไกล

ครูสาวเปิด TeamViewer บนเครื่องปลายทางและแจ้ง TeamViewer ID กับ Password ผ่านบทสนทนา ผู้เล่นต้องอ่านข้อมูล เปิด TeamViewer บนเครื่องของตน และพิมพ์ข้อมูลให้ถูกต้อง เมื่อเชื่อมต่อแล้วจึงตรวจสอบ Desktop ของครูสาวและแก้ไขปัญหาเสียง

## บทสนทนาเริ่มภารกิจ

โทรศัพท์บนโต๊ะทำงานดังขึ้น ผู้เล่นกด `E` เพื่อรับสาย

**ครูสาว:**

> สวัสดีค่ะ ตอนนี้เปิดวิดีโอประกอบการสอนแล้วไม่มีเสียง ช่วยตรวจสอบให้หน่อยได้ไหมคะ

**ผู้เล่น:**

> ได้ครับ ตอนนี้ผมต้องเฝ้าระบบอยู่ในห้อง Data Center ขอเชื่อมต่อไปตรวจสอบเครื่องจากระยะไกลนะครับ

**ผู้เล่น:**

> กรุณาเปิด TeamViewer แล้วแจ้ง TeamViewer ID และ Password ที่แสดงอยู่บนหน้าจอครับ

**ครูสาว:**

> เปิดแล้วค่ะ
>
> TeamViewer ID: `482 731 965`
>
> Password: `N7q4P2`

**ผู้เล่น:**

> รับทราบครับ กรุณารอสักครู่ ผมจะเชื่อมต่อเข้าไปตรวจสอบ

ข้อมูล ID และ Password เป็นข้อมูลสมมติภายในเกม ไม่เชื่อมโยงกับเครื่องหรือบัญชีจริง

หลังจบบทสนทนา ระบบแสดงข้อความ:

> ได้รับภารกิจ: เชื่อมต่อเครื่องครูสาวด้วย TeamViewer และแก้ไขปัญหาเสียง

## วัตถุประสงค์ของภารกิจ

ผู้เล่นต้องสามารถ:

1. อธิบายได้ว่าซอฟต์แวร์ควบคุมระยะไกลใช้ตรวจสอบและควบคุมเครื่องปลายทางโดยไม่ต้องอยู่หน้าเครื่อง
2. ระบุได้ว่า TeamViewer ใช้ TeamViewer ID และ Password สำหรับการเชื่อมต่อในรูปแบบที่หนังสืออธิบาย
3. พิมพ์ TeamViewer ID และ Password ของเครื่องปลายทางด้วยตนเองได้
4. เข้าใจว่าเครื่องทั้งสองต้องเปิดโปรแกรมและเชื่อมต่อเครือข่ายอยู่
5. ควบคุม Desktop ปลายทางและแก้ไขปัญหาด้านซอฟต์แวร์เบื้องต้นได้
6. จบ Remote Session อย่างถูกต้องเมื่อดำเนินการเสร็จ
7. แยกหลักการของ TeamViewer และ AnyDesk ได้ในระดับเบื้องต้น

## เงื่อนไขก่อนเชื่อมต่อ

ระบบแสดงรายการตรวจสอบให้ผู้เล่นทราบก่อนเปิด TeamViewer:

```text
✓ คอมพิวเตอร์ของผู้เล่นเปิดอยู่
✓ คอมพิวเตอร์ของครูสาวเปิดอยู่
✓ เครื่องทั้งสองเชื่อมต่อเครือข่าย
✓ เครื่องทั้งสองเปิด TeamViewer
✓ ครูสาวอนุญาตให้เจ้าหน้าที่เชื่อมต่อ
```

หากเครื่องปลายทางปิด ไม่มีเครือข่าย หรือไม่ได้เปิดโปรแกรม การเชื่อมต่อระยะไกลในภารกิจนี้จะไม่สามารถดำเนินการได้

## รูปแบบโปรแกรมจำลอง

โปรแกรม TeamViewer ในภารกิจเป็นซอฟต์แวร์จำลองภายในเกม มีองค์ประกอบเฉพาะที่จำเป็นต่อการเรียนรู้ ได้แก่:

- ช่อง `Partner ID`
- ปุ่ม `Connect`
- หน้าต่าง `Authentication`
- ช่อง `Password`
- ปุ่ม `Log On`
- แถบสถานะ Remote Session
- ปุ่ม `End Session`

เกมไม่เรียกใช้ TeamViewer จริง ไม่เชื่อมต่อคอมพิวเตอร์จริง และไม่ส่งข้อมูลออกจากเกม

## ขั้นตอนการเล่น

### ช่วงที่ 1: รับข้อมูลสำหรับเชื่อมต่อ

1. ผู้เล่นรับโทรศัพท์จากครูสาว
2. ครูสาวแจ้ง TeamViewer ID และ Password ผ่านบทสนทนา
3. ระบบเก็บบทสนทนาไว้ในประวัติภารกิจ
4. ผู้เล่นสามารถเปิดประวัติเพื่อดูข้อมูลอีกครั้งได้

การเปิดดูประวัติไม่หักคะแนน เพราะภารกิจต้องการวัดความเข้าใจขั้นตอนการเชื่อมต่อ ไม่ได้วัดความสามารถในการจำตัวเลขและรหัสผ่าน

### ช่วงที่ 2: เปิด TeamViewer

1. ผู้เล่นกด `E` ที่คอมพิวเตอร์ของตนในห้อง Data Center
2. กล้องซูมเข้าสู่หน้าจอ
3. Desktop จำลองปรากฏขึ้น
4. ผู้เล่นเปิดโปรแกรม TeamViewer จากไอคอนบน Desktop
5. ระบบแสดงหน้าต่างสำหรับควบคุมเครื่องระยะไกล

### ช่วงที่ 3: กรอก TeamViewer ID

1. ผู้เล่นคลิกช่อง `Partner ID`
2. พิมพ์ TeamViewer ID ที่ได้รับจากครูสาวด้วยตนเอง
3. กดปุ่ม `Connect`

ค่าที่ถูกต้อง:

```text
482 731 965
```

ระบบยอมรับทั้งรูปแบบที่มีและไม่มีช่องว่าง เช่น:

```text
482 731 965
482731965
```

หาก ID ไม่ถูกต้อง ระบบแสดง:

> ไม่พบเครื่องปลายทาง กรุณาตรวจสอบ TeamViewer ID แล้วลองอีกครั้ง

ผู้เล่นสามารถเปิดประวัติบทสนทนาเพื่อตรวจสอบค่าได้ ระบบไม่กรอกค่าให้โดยอัตโนมัติและไม่เฉลยค่าที่ถูกในข้อความแจ้งเตือน

### ช่วงที่ 4: กรอก Password

เมื่อ TeamViewer ID ถูกต้อง ระบบเปิดหน้าต่าง `Authentication`

1. ผู้เล่นคลิกช่อง `Password`
2. พิมพ์ Password ที่ได้รับจากครูสาวด้วยตนเอง
3. กดปุ่ม `Log On`

ค่าที่ถูกต้อง:

```text
N7q4P2
```

การตรวจ Password แยกตัวอักษรพิมพ์เล็กและพิมพ์ใหญ่

หาก Password ไม่ถูกต้อง ระบบแสดง:

> รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบข้อมูลจากผู้ใช้ปลายทาง

เมื่อกรอกถูกต้อง ระบบแสดงข้อความ:

> Connection established

จากนั้นเปิด Desktop ของครูสาวภายในหน้าต่าง Remote Session

## หน้า Remote Desktop

ด้านบนของหน้าจอแสดงแถบสถานะ:

```text
Remote Session
Connected to: TEACHER-PC
Session status: Active
[End Session]
```

ผู้เล่นสามารถควบคุมเมาส์ เปิดเมนู และเปลี่ยนการตั้งค่าบน Desktop ของครูสาวได้ แต่ไม่สามารถออกนอกขอบเขตโปรแกรมจำลองที่กำหนด

## ปัญหาที่ต้องแก้ไข

### อาการ

ครูสาวเปิดวิดีโอประกอบการสอน แต่ไม่ได้ยินเสียงจากคอมพิวเตอร์

### สาเหตุ

เสียงของคอมพิวเตอร์ถูกตั้งเป็น Mute

### สิ่งที่ผู้เล่นต้องทำ

1. คลิกไอคอนลำโพงบน Taskbar ของเครื่องครูสาว
2. ตรวจสอบสถานะและพบว่าเสียงถูกปิด
3. กดปุ่มลำโพงเพื่อยกเลิก Mute
4. ปรับระดับเสียงให้อยู่ระหว่าง 50–70 เปอร์เซ็นต์
5. กดปุ่ม `ทดสอบเสียง`
6. รอการยืนยันจากครูสาว

หากระดับเสียงต่ำกว่า 50 เปอร์เซ็นต์ ระบบแสดง:

> เปิดเสียงแล้ว แต่ระดับเสียงยังเบาเกินไป กรุณาปรับให้อยู่ในระดับที่เหมาะสม

หากปรับสูงกว่า 70 เปอร์เซ็นต์ ระบบแสดง:

> ระดับเสียงดังเกินความจำเป็น กรุณาปรับให้อยู่ในช่วงที่กำหนด

เมื่อดำเนินการถูกต้อง:

**ครูสาว:**

> ได้ยินเสียงแล้วค่ะ ตอนนี้ใช้งานได้ตามปกติ ขอบคุณค่ะ

## การจบ Remote Session

หลังครูสาวยืนยันว่าแก้ไขสำเร็จ ผู้เล่นต้องจบการเชื่อมต่ออย่างถูกต้อง:

1. กดปุ่ม `End Session`
2. ระบบถามยืนยันว่า `ต้องการยุติการควบคุมเครื่องปลายทางหรือไม่`
3. เลือก `Disconnect`
4. สถานะเปลี่ยนจาก `Active` เป็น `Session ended`
5. ปิดโปรแกรม TeamViewer
6. ปิดคอมพิวเตอร์ของผู้เล่นในห้อง Data Center

ผู้เล่นไม่ปิดคอมพิวเตอร์ของครูสาว เพราะครูสาวยังต้องใช้งานต่อ

เมื่อปิดคอมพิวเตอร์ของผู้เล่น ระบบแสดงหน้าสรุปและจบภารกิจ

## หน้าสรุปความรู้

หลังจบ Remote Session ระบบแสดง:

```text
TeamViewer
- เครื่องทั้งสองต้องเปิดโปรแกรมและเชื่อมต่อเครือข่าย
- เครื่องปลายทางแจ้ง TeamViewer ID และ Password
- ผู้ดูแลกรอก ID และ Password เพื่อขอเชื่อมต่อ

AnyDesk
- เครื่องทั้งสองต้องเปิดโปรแกรมและเชื่อมต่อเครือข่าย
- เครื่องปลายทางแจ้ง AnyDesk Address
- ผู้ดูแลกรอก Address และรอให้เครื่องปลายทางกด Accept

ซอฟต์แวร์ควบคุมระยะไกล
- ใช้มองเห็นและควบคุม Desktop ปลายทาง
- เหมาะสำหรับตรวจสอบและแก้ไขปัญหาด้านซอฟต์แวร์เบื้องต้น
- ต้องได้รับอนุญาตจากผู้ใช้หรือผู้ดูแลเครื่องปลายทาง
```

## ระบบคะแนน

- คะแนนเริ่มต้น 100 คะแนน
- กรอก TeamViewer ID ผิดครั้งละ 5 คะแนน
- กรอก Password ผิดครั้งละ 5 คะแนน
- เลือกปิดโปรแกรมโดยไม่กด `End Session` หัก 10 คะแนน และให้กลับไปจบ Session ให้ถูกต้อง
- การเปิดดูประวัติบทสนทนาไม่หักคะแนน
- การปรับระดับเสียงผิดช่วงครั้งแรกให้คำแนะนำโดยไม่หักคะแนน
- ผู้เล่นต้องเชื่อมต่อ แก้ไขปัญหา และจบ Session สำเร็จจึงผ่านภารกิจ

## เงื่อนไขสำเร็จ

ภารกิจสำเร็จเมื่อผู้เล่นทำครบทุกข้อ:

- รับ TeamViewer ID และ Password จากครูสาว
- พิมพ์ Partner ID ด้วยตนเองและกด Connect
- พิมพ์ Password ด้วยตนเองและกด Log On
- เชื่อมต่อไปยัง Desktop ของครูสาวสำเร็จ
- ยกเลิก Mute และปรับระดับเสียงให้อยู่ในช่วงที่กำหนด
- ทดสอบเสียงและได้รับการยืนยันจากครูสาว
- กด End Session และ Disconnect อย่างถูกต้อง
- ปิด TeamViewer
- ปิดคอมพิวเตอร์ของผู้เล่นในห้อง Data Center

## ขอบเขตเนื้อหาที่ไม่ใช้ในภารกิจ

- การกรอก IP Address เพื่อเชื่อมต่อ TeamViewer
- การสร้างบัญชี TeamViewer จริง
- การเชื่อมต่อเครื่องจริงผ่านอินเทอร์เน็ต
- การตั้งค่า Unattended Access
- การติดตั้งหรือกำหนดค่าซอฟต์แวร์ TeamViewer จริง
- การถ่ายโอนไฟล์จริงระหว่างเครื่อง
- การซ่อมแซมอุปกรณ์ทางกายภาพจากระยะไกล
- การควบคุมเครื่องโดยไม่ได้รับอนุญาต
- การเปิดเผย ID หรือ Password ให้บุคคลที่ไม่เกี่ยวข้อง

## สรุปผลการเรียนรู้

ผู้เล่นได้เรียนรู้ว่าซอฟต์แวร์ควบคุมเครื่องระยะไกลช่วยให้ผู้ดูแลระบบมองเห็นและควบคุมเครื่องปลายทางได้โดยไม่ต้องเดินทางไปหน้าเครื่อง การเชื่อมต่อ TeamViewer ในรูปแบบที่หนังสืออธิบายต้องใช้ TeamViewer ID และ Password ของเครื่องปลายทาง เมื่อได้รับอนุญาตและเชื่อมต่อสำเร็จ ผู้ดูแลสามารถตรวจสอบและแก้ไขปัญหาด้านซอฟต์แวร์เบื้องต้นได้ และต้องยุติ Remote Session อย่างถูกต้องเมื่อทำงานเสร็จ
